# XIII-6 RANSAC

::: lead
관측값 중 일부가 완전히 틀렸을 때, 그 이상치가 답을 끌어당기지 못하게 하려면 어떻게 해야 하는가.
:::

## 1. 문제

점 일곱 개가 있고 그중 다섯 개는 거의 직선 $y = x$ 위에 있다. 나머지 둘은 관계없는 값이다 — 센서 노이즈, 잘못 매칭된 특징점, 다른 물체에서 튄 반사일 수 있다.

이 일곱 점 전부로 최소제곱 직선을 맞추면 무슨 일이 일어나는지 직접 계산해 본다. 점은 $(0,0), (1,1), (2,2), (3,3), (4,7), (5,5), (1,4)$다. 뒤의 두 개 $(4,7)$과 $(1,4)$가 이상치다.

일곱 점 전부로 최소제곱 직선(기울기 $m$, 절편 $b$)을 구하면 $y \approx 1.20x + 0.66$이 나온다. 참값 $y = x$와 비교하면 기울기가 20% 어긋나 있다. **점 두 개, 전체의 29%가 답을 이만큼 끌어당겼다.** 최소제곱은 오차 제곱의 합을 최소화하므로 멀리 떨어진 점일수록 그 제곱이 커져 더 세게 끌어당긴다. 이상치가 안전한 데이터가 아니라 가장 위험한 데이터인 이유가 이것이다.

이 문제는 직선 피팅에 국한되지 않는다. 카메라 두 장에서 특징점을 짝지을 때 잘못 매칭된 쌍이 섞이고, 라이다 점군에서 바닥 평면을 뽑을 때 바닥이 아닌 점이 섞이고, [XIII-5 ICP](#/xiii-5)에서 대응점 일부가 실제로는 대응이 아니다. **관측치 중 어느 것이 진짜(inlier)이고 어느 것이 가짜(outlier)인지 미리 알 수 없는 채로 모델을 맞춰야 하는 상황이 널려 있다.** RANSAC(Random Sample Consensus)은 이 상황을 정면으로 겨냥한 방법이다.

## 2. 아이디어

RANSAC의 발상은 반대로 뒤집는 데 있다. 전체 데이터로 한 번에 모델을 맞추는 대신, **아주 작은 표본으로 모델 후보를 여러 개 만들고, 그중 가장 많은 점이 동의하는 후보를 취한다.**

```text nolines
sample minimal set -> fit candidate model -> count inliers (|error| <= eps)
        ^                                                        |
        +-------------- keep best model, repeat k times ---------+
```

**최소 표본(minimal sample).** 직선은 점 두 개, 평면은 점 세 개, 원은 점 세 개 — 모델을 유일하게 결정하는 데 필요한 최소 개수만 무작위로 뽑는다. 왜 최소인가는 확률로 답이 나온다. 표본에 이상치가 하나도 안 섞일 확률은 (인라이어 비율)^(표본 크기)다. 표본이 커질수록 이 확률은 급격히 떨어진다. 인라이어 비율이 70%라면 표본 2개는 깨끗할 확률이 $0.7^2 = 0.49$지만 표본 5개는 $0.7^5 \approx 0.168$로 줄어든다. **표본을 작게 유지하는 것이 깨끗한 표본을 뽑을 확률을 지키는 전략이다.**

**적합(fit).** 뽑은 최소 표본만으로 모델을 정한다. 이 단계는 표본 두 점을 지나는 직선을 구하는 정도로 항상 닫힌 형태이고 빠르다.

**동의 집계(count inliers).** 이 모델을 전체 데이터에 대입해, 오차가 임계값 $\varepsilon$ 이내인 점의 개수를 센다. 이 개수가 그 모델의 "지지율"이다. 표본이 우연히 이상치를 하나라도 포함했다면 모델 자체가 어긋나 있어 지지하는 점이 적게 나온다. 표본이 운 좋게 전부 인라이어였다면 진짜 구조와 가까운 모델이 나와 많은 점이 동의한다.

**최선 갱신(keep best).** 시행을 $k$번 반복하며 지지율이 가장 높은 모델을 계속 들고 있는다. 시행 횟수 $k$는 무한정 늘리는 값이 아니라 확률로 정해지는 값이다. 인라이어 비율 $w$, 표본 크기 $n$, 목표 성공 확률 $p$가 주어지면

$$k = \frac{\log(1-p)}{\log(1 - w^n)}$$

가 필요한 시행 횟수다. $w = 0.7$, $n = 2$, $p = 0.99$를 넣으면 $\log(0.01) / \log(1 - 0.49) = -4.605 / -0.673 \approx 6.84$, 올림해서 **7번**이면 된다. 표본이 커지면($n$이 커지면) 분모의 $w^n$이 작아져 $k$가 급격히 커진다는 것이 표본을 최소로 유지해야 하는 이유를 다시 확인해 준다.

동의 집계가 끝나면 대개 한 단계가 더 있다 — 최종 승자로 뽑힌 모델을 표본 2점이 아니라 **그 모델이 인라이어로 판정한 점 전체**로 다시 최소제곱 피팅한다(refit). 최소 표본으로 구한 모델은 우연에 좌우되지만, 인라이어 전체로 다시 피팅하면 그 우연이 평균으로 씻겨 나간다.

::: note
RANSAC이 찾는 것은 "가장 정확한 모델"이 아니라 "가장 많은 점이 지지하는 모델"이다. 데이터의 절반이 이상치라도 나머지 절반이 하나의 일관된 구조를 이룬다면 RANSAC은 그 구조를 찾아낸다. 반대로 인라이어 비율이 정말 낮으면(50% 미만으로 떨어지면) $k$가 기하급수적으로 커지고, 어느 시점부터는 이 방법 자체가 비현실적이다.
:::

## 3. 손으로 따라가기

::: trace
점 목록(인덱스 0~6): $P_0(0,0),\ P_1(1,1),\ P_2(2,2),\ P_3(3,3),\ P_4(4,7),\ P_5(5,5),\ P_6(1,4)$. 임계값 $\varepsilon = 0.5$, 오차는 수직 거리 $|y - (mx+b)|$로 잰다. 재현성을 위해 시행마다 뽑을 표본을 미리 고정했다 — 실전에서는 매 시행 무작위로 뽑는다.

갱신 규칙: 지지 개수가 **지금까지의 최선보다 엄격히 클 때만** 갱신한다(동률이면 먼저 찾은 모델을 지킨다).

| 1 | (4, 6) | 1.000 | 3.000 | [4, 6] | 2 | 2 | 예 |
| 2 | (0, 4) | 1.750 | 0.000 | [0, 4] | 2 | 2 |  |
| 3 | (1, 5) |  |  |  |  |  |  |
| 4 | (2, 6) |  |  |  |  |  |  |

시행 1의 표본은 $(P_4, P_6) = ((4,7), (1,4))$다. $m = (4-7)/(1-4) = 1.0$, $b = 7 - 1.0 \times 4 = 3.0$ — 두 이상치만으로 만든 직선이라 나머지 다섯 점 중 누구도 지지하지 않는다.

시행 2는 갱신 칸이 비어 있다. 개수가 시행 1과 같은 2인데 왜 갱신이 "아니오"인지 규칙에서 답을 찾아라.

**나머지를 채워라.** 시행 3은 $(P_1, P_5) = ((1,1),(5,5))$, 시행 4는 $(P_2, P_6) = ((2,2),(1,4))$, 시행 5는 $(P_3, P_0) = ((3,3),(0,0))$이다. 각 직선에 일곱 점 전부의 수직 거리를 재 $\varepsilon = 0.5$ 이내인지 판정하라.

| 1 | (4, 6) | 1.000 | 3.000 | [4, 6] | 2 | 2 | 예 |

시행 3의 표본 $(P_1, P_5) = ((1,1),(5,5))$은 우연히 둘 다 인라이어였다. 그 결과 나온 직선 $y = x$가 참값과 정확히 일치하고, 지지하는 점이 5개로 뛴다 — 시행 1·2가 만든 "이상치가 섞인" 모델을 단번에 밀어낸다.

시행 5는 표본 $(P_3, P_0)$도 우연히 둘 다 인라이어라 같은 직선 $y=x$가 다시 나온다. 개수는 똑같이 5지만 **최선보다 크지 않으므로 갱신하지 않는다** — 최선 모델은 시행 3에서 찾은 것이 그대로 유지된다. 이 규칙이 없으면(예: `>=`로 갱신) 마지막에 찾은 동률 모델로 계속 바뀌기만 하고, 어느 시행이 "진짜 첫 발견"인지 기록이 사라진다.

최종 승자는 $m=1.000,\ b=0.000$, 인라이어는 $\{P_0, P_1, P_2, P_3, P_5\}$ 다섯 개. 참값 $y=x$와 정확히 같다 — 표본 두 개가 우연히 깨끗했던 순간 답이 나왔다.

## 4. 구현

::: dual
```python title="RANSAC — 직선 피팅"
def fit_line(p1, p2):
    (x1, y1), (x2, y2) = p1, p2
    m = (y2 - y1) / (x2 - x1)
    b = y1 - m * x1
    return m, b


def count_inliers(points, m, b, threshold):
    inliers = [i for i, (x, y) in enumerate(points) if abs(y - (m * x + b)) <= threshold]
    return inliers


def ransac_line(points, trials, threshold):
    best_count, best_model, best_inliers = -1, None, []
    for t, (i, j) in enumerate(trials):
        m, b = fit_line(points[i], points[j])
        inliers = count_inliers(points, m, b, threshold)
        count = len(inliers)
        updated = count > best_count            # 엄격히 더 좋을 때만 갱신 — 동률은 먼저 찾은 모델을 지킨다
        if updated:
            best_count, best_model, best_inliers = count, (m, b), inliers
        print(f"trial={t + 1} sample=({i},{j}) m={m:.3f} b={b:.3f} "
              f"inliers={inliers} count={count} best={best_count} updated={updated}")
    return best_model, best_inliers


points = [(0, 0), (1, 1), (2, 2), (3, 3), (4, 7), (5, 5), (1, 4)]
trials = [(4, 6), (0, 4), (1, 5), (2, 6), (3, 0)]     # 표본 순서는 재현성을 위해 고정한다
model, inliers = ransac_line(points, trials, threshold=0.5)
print(f"final model: y = {model[0]:.3f}x + {model[1]:.3f}, inliers={inliers}")
```
```cpp title="RANSAC — 직선 피팅"
#include <cmath>
#include <cstdio>
#include <utility>
#include <vector>
using namespace std;

pair<double,double> fit_line(pair<double,double> p1, pair<double,double> p2) {
    double x1 = p1.first, y1 = p1.second, x2 = p2.first, y2 = p2.second;
    double m = (y2 - y1) / (x2 - x1);
    double b = y1 - m * x1;
    return {m, b};
}

vector<int> count_inliers(const vector<pair<double,double>>& points, double m, double b, double threshold) {
    vector<int> inliers;
    for (int i = 0; i < (int)points.size(); i++) {
        double x = points[i].first, y = points[i].second;
        if (fabs(y - (m * x + b)) <= threshold) inliers.push_back(i);
    }
    return inliers;
}

int main() {
    vector<pair<double,double>> points = {{0,0},{1,1},{2,2},{3,3},{4,7},{5,5},{1,4}};
    vector<pair<int,int>> trials = {{4,6},{0,4},{1,5},{2,6},{3,0}};  // 표본 순서는 재현성을 위해 고정한다
    double threshold = 0.5;

    int best_count = -1;
    pair<double,double> best_model;
    vector<int> best_inliers;

    for (int t = 0; t < (int)trials.size(); t++) {
        auto [i, j] = trials[t];
        auto [m, b] = fit_line(points[i], points[j]);
        auto inliers = count_inliers(points, m, b, threshold);
        int count = inliers.size();
        bool updated = count > best_count;  // 엄격히 더 좋을 때만 갱신 — 동률은 먼저 찾은 모델을 지킨다
        if (updated) { best_count = count; best_model = {m, b}; best_inliers = inliers; }

        printf("trial=%d sample=(%d,%d) m=%.3f b=%.3f inliers=[", t + 1, i, j, m, b);
        for (int k = 0; k < (int)inliers.size(); k++) printf("%s%d", k ? ", " : "", inliers[k]);
        printf("] count=%d best=%d updated=%s\n", count, best_count, updated ? "True" : "False");
    }
    printf("final model: y = %.3fx + %.3f, inliers=[", best_model.first, best_model.second);
    for (int k = 0; k < (int)best_inliers.size(); k++) printf("%s%d", k ? ", " : "", best_inliers[k]);
    printf("]\n");
    return 0;
}
```

**복잡도:** 시간 $O(k \cdot n)$ — 시행 $k$번마다 표본 적합은 $O(1)$(최소 표본이 상수 개)이고 인라이어를 세는 데 전체 점 $n$개를 훑으므로 시행당 $O(n)$, 총 $O(kn)$이다. $k$는 §2의 확률식으로 정해지는 상수이지 $n$에 의존하지 않는다. 공간 $O(n)$ — 인라이어 목록을 담는다.

| 언어 차이 | Python | C++ |
|---|---|---|
| 표본·모델 반환 | 튜플 `(m, b)`을 그대로 반환 | `pair<double,double>`, 구조적 바인딩 `auto [m, b]`로 받는다(C++17) |
| 리스트 컴프리헨션 | `[i for i, (x,y) in enumerate(points) if ...]` | 조건에 맞는 인덱스를 직접 `push_back`하는 루프 |
| 부동소수 서식 | f-string `{m:.3f}` | `printf("%.3f", m)` |
| 불리언 출력 | `True`/`False` (Python 기본 표기) | 코드에서 문자열로 직접 변환(`updated ? "True" : "False"`)해 맞춘다 |

::: pitfall
- **임계값 $\varepsilon$을 데이터 스케일과 무관하게 고정한다.** 센서 노이즈의 표준편차보다 훨씬 작으면 진짜 인라이어까지 걸러내고, 훨씬 크면 이상치까지 통과시켜 RANSAC이 이상치 제거 도구로 기능하지 않는다. 값은 센서 사양(예: 라이다의 측정 오차)에서 역산한다.
- **오차 비교에 `==`나 부동소수 경계를 소홀히 다룬다.** `abs(y - pred) <= threshold`의 `threshold` 자체가 근사값이면 경계에 있는 점의 판정이 뒤집힐 수 있다 — [X-7 부동소수점의 함정](#/x-7)의 EPS 논의가 그대로 적용된다.
- **표본 크기를 필요 이상으로 키운다.** 표본이 최소보다 크면 "표본이 전부 인라이어일 확률" $w^n$이 즉시 줄어들어 같은 성공 확률을 얻는 데 필요한 시행 횟수 $k$가 폭증한다.
- **승자 표본만으로 끝낸다.** 최소 표본 2점으로 결정된 모델은 그 2점의 정밀도에 그대로 묶인다. 인라이어 전체로 재적합(refit)하는 마지막 단계를 빼먹으면 우연히 뽑힌 표본의 오차가 최종 모델에 그대로 남는다.
- **동률 처리 규칙을 정하지 않는다.** "크거나 같으면 갱신"과 "엄격히 크면 갱신"은 동률에서 다른 모델을 고른다. 어느 쪽이든 상관없지만, 정하지 않으면 구현마다 결과가 갈린다.
:::

## 5. 어디에 쓰이는가

**카메라 캘리브레이션과 자세 추정(homography, fundamental matrix)이 RANSAC 없이는 성립하지 않는다.** 두 이미지에서 특징점을 매칭하면 잘못된 매칭이 항상 섞인다 — 비슷하게 생긴 두 창문, 반복되는 타일 무늬가 서로 다른 지점을 같은 특징으로 착각하게 만든다. 이 오매칭들이 이상치가 되고, RANSAC이 최소 표본(호모그래피는 점 4쌍, 기본 행렬은 점 8쌍)으로 후보를 반복 생성해 진짜 기하 관계를 지지하는 표본을 찾는다. [XIII-9 허프 변환과 특징점(ORB) 매칭](#/xiii-9)에서 만드는 매칭 쌍이 바로 이 입력이다.

**LiDAR 점군에서 바닥 평면을 뽑는 데도 같은 구조가 쓰인다.** 표본을 점 3개로 바꾸면 평면 모델이 되고, 나머지 절차는 동일하다. 바닥이 아닌 점(사람, 가구, 벽)은 이상치로 취급되어 자연히 걸러진다.

**[XIII-5 ICP](#/xiii-5)의 대응점 문제와 정확히 같은 구조다.** ICP는 최근접이라는 대응 규칙 하나로 전체 점을 한 번에 신뢰하지만, RANSAC은 작은 표본으로 여러 후보를 만들고 다수결로 검증한다. 실무에서는 둘을 합쳐 쓴다 — ICP의 대응 후보 중 RANSAC으로 인라이어만 골라 회전·이동을 추정하는 방식이 이상치가 많은 실외 라이다 데이터에서 특히 쓰인다.

::: interview
**"RANSAC의 시행 횟수는 어떻게 정합니까."**
답변 뼈대는 확률식이다. 인라이어 비율 $w$, 표본 크기 $n$, 목표 성공 확률 $p$가 주어지면 $k = \log(1-p) / \log(1-w^n)$번이면 충분하다. $w$를 미리 모른다면 보수적으로 낮게 잡거나(예: 0.5), 시행 중간에 지금까지의 최고 지지율로 $w$를 갱신해 $k$를 다시 계산하는 적응적 방식을 쓴다.

**"표본을 최소 크기로 뽑는 이유는 무엇입니까."**
표본이 전부 인라이어일 확률이 $w^n$이고, $n$이 커질수록 이 값이 급격히 작아지기 때문이다. 표본을 크게 하면 모델 하나의 안정성은 늘지만, 애초에 깨끗한 표본을 뽑을 확률 자체가 줄어 전체 시행 횟수가 오히려 늘어난다.

**"인라이어 비율이 30%보다 낮으면 어떻게 됩니까."**
$w^n$이 매우 작아져 $k$가 비현실적으로 커진다. 이 경우 RANSAC 단독보다 사전 필터링(명백한 이상치를 다른 신호로 먼저 제거)이나 점진적 표본 선택(MLESAC, PROSAC처럼 품질이 높은 점을 우선 표본으로 뽑는 변형)을 함께 쓴다.
:::

## 연습

이 챕터도 코딩테스트 대표문제가 약하다. RANSAC의 핵심은 무작위 표본과 확률적 반복 횟수이고, 결정론적 정답을 요구하는 채점 환경과는 성격이 다르다. 설계 판단으로 대신한다.

::: quiz
각 상황에서 ① 이상치의 정체는 무엇인가 ② 최소 표본의 크기는 얼마인가 ③ 임계값을 무엇에 근거해 정하는가를 답하라.

**1. 체스판으로 카메라 캘리브레이션**
체스판 코너를 검출해 카메라의 내부 파라미터를 구한다. 코너 검출기가 가끔 조명 반사를 코너로 오검출한다.
- 이상치: 반사로 생긴 가짜 코너. 실제 체스판 격자 위치와 대응되지 않는다.
- 표본 크기: 호모그래피 추정이면 대응점 4쌍.
- 임계값: 코너 검출기의 픽셀 단위 정밀도(보통 1픽셀 이내)에서 역산한다. 검출 정밀도보다 훨씬 크게 잡으면 진짜 오검출도 통과시킨다.

**2. 실외 라이다에서 지면 추출**
차량 라이다가 도로면과 주변 차량·가로수를 함께 스캔했다.
- 이상치: 도로면이 아닌 모든 점(차량, 가로수, 사람).
- 표본 크기: 평면이므로 점 3개.
- 임계값: 도로의 실제 굴곡(요철, 경사)과 라이다의 거리 오차를 함께 고려한다. 너무 좁히면 완만한 오르막에서 도로 자체가 이상치로 잘린다.

**3. 두 이미지의 특징점 매칭**
ORB로 뽑은 특징점을 두 이미지 사이에서 매칭했다. 반복되는 벽돌 무늬 때문에 오매칭이 많다.
- 이상치: 기하적으로 불가능한 매칭 — 실제 카메라 이동으로는 설명되지 않는 대응 쌍.
- 표본 크기: 기본 행렬(fundamental matrix)이면 점 8쌍, 필수 행렬(essential matrix, 캘리브레이션 기지)이면 5쌍으로 줄일 수 있다.
- 임계값: 대응점이 추정된 기하 관계에서 벗어난 정도(재투영 오차)를 픽셀 단위로 재고, 특징점 검출기의 위치 정밀도에서 역산한다.
:::

## 요약

- 최소제곱은 이상치 하나에도 흔들린다 — 오차 제곱을 최소화하므로 먼 점일수록 더 세게 끌어당긴다. 예제에서 이상치 두 개가 기울기를 20% 틀어지게 만들었다.
- RANSAC은 **최소 표본으로 후보 모델을 여러 개 만들고, 가장 많은 점이 지지하는 후보를 취한다.** 전체 데이터로 한 번에 맞추는 대신 작은 표본을 반복해서 던진다.
- 표본을 최소로 유지하는 이유는 확률이다 — 표본이 전부 인라이어일 확률이 $w^n$이고, $n$이 커지면 이 값이 급격히 줄어 필요한 시행 횟수가 폭증한다.
- 시행 횟수 $k = \log(1-p)/\log(1-w^n)$는 감이 아니라 계산으로 정해지는 값이다.
- 갱신 규칙(엄격히 클 때만 갱신)이 동률 상황의 재현성을 결정한다. 예제 시행 5는 시행 3과 개수가 같아도 최선을 뺏지 못한다.
- 승자로 끝나지 않는다. 인라이어 전체로 다시 피팅(refit)하는 마지막 단계가 최소 표본의 우연을 씻어낸다.
- 카메라 캘리브레이션·특징점 매칭의 이상치 제거·평면 추출·[XIII-5 ICP](#/xiii-5)의 대응점 정제까지, "일부 관측이 틀렸다"는 조건이 있는 곳이면 어디든 같은 구조가 쓰인다.
