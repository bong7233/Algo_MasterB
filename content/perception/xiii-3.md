# XIII-3 칼만 필터와 EKF

::: lead
잡음 섞인 측정값 하나와 모델이 예측한 값 하나가 있을 때, 둘을 어떤 비율로 섞어야 최선의 추정이 나오는가.
:::

## 1. 문제

로봇에 GPS 모듈을 하나 달았다. 1초마다 위치를 읽는다. 로봇은 초속 1미터로 똑바로 걷고 있는데, GPS가 찍어 주는 값은 0.8, 1.6, 3.4, 3.7, 5.2, 5.9처럼 들쭉날쭉하다. 어떤 초에는 실제보다 앞서 찍히고 어떤 초에는 뒤처진다. 이 숫자만 보고 "지금 로봇이 어디 있는가"를 답해야 한다.

가장 단순한 답은 **방금 읽은 값을 그대로 믿는 것**이다. 그러면 위치 추정치가 GPS 잡음만큼 매초 덜컹거린다. 로봇 팔이나 드론처럼 그 추정치를 제어 루프에 바로 먹이는 시스템에서는 이 떨림이 그대로 진동으로 나타난다.

다음으로 떠오르는 답은 **지금까지 읽은 값을 전부 평균 내는 것**이다. 떨림은 줄지만 대가가 크다. 로봇이 실제로 이동하고 있으므로 오래된 값들은 이제 틀린 값이고, 평균은 항상 실제 위치보다 뒤처진다. 최근 값에 더 큰 가중치를 주는 이동평균으로 타협해도, "얼마나 최근 것에 가중치를 줄 것인가"라는 숫자를 결국 손으로 정해야 하고 그 숫자는 상황마다 다시 조정해야 한다.

[XIII-2 베이즈 필터의 뼈대](#/xiii-2)는 이 문제를 예측과 보정 두 단계로 쪼갠다는 답을 준다. 로봇의 운동 모델로 다음 위치를 **예측**하고, GPS 측정값으로 그 예측을 **보정**한다. 그런데 그 챕터는 "사후 확률을 어떤 형태로 표현할 것인가"를 열어 둔 채로 남긴다. 확률 분포를 표현하는 방법을 정하지 않으면 예측과 보정이 구체적인 계산으로 내려가지 않는다. 칼만 필터는 이 빈칸을 정확히 하나의 방식으로 채운다 — **그 분포를 평균과 분산 두 숫자만으로 표현되는 가우시안 하나로 못박는다.** 그 순간 예측과 보정은 각각 덧셈 몇 번과 나눗셈 한 번으로 끝나는 닫힌 식이 된다.

## 2. 아이디어

### 2.1 확신이 큰 쪽이 평균을 더 많이 끌어당긴다

추정치를 가우시안으로 표현한다는 것은 숫자 하나(평균, 지금 가장 그럴듯한 위치)와 숫자 하나(분산, 그 추정이 얼마나 불확실한가)로 상태를 통째로 요약한다는 뜻이다. 로봇의 현재 믿음이 평균 $\hat{x}$, 분산 $P$인 가우시안이고, 새 측정값 $z$가 평균 $z$, 분산 $R$인 또 다른 가우시안으로 표현된다고 하자 — $R$은 GPS 제조사가 알려 주는 측정 잡음의 크기다.

두 가우시안을 곱하면 다시 가우시안이 나온다는 것이 정규분포의 성질이고, 그 결과의 평균은 **두 원래 평균의 분산 가중 평균**이다. 분산이 작을수록(확신이 클수록) 그쪽 평균이 결과를 더 세게 끌어당긴다. GPS가 지금 유난히 흔들렸다면($R$이 크다면) 결과는 예측 쪽으로 붙고, 반대로 로봇이 얼마나 움직였는지 확신이 없다면($P$가 크다면) 결과는 측정값 쪽으로 붙는다. **칼만 필터가 하는 일은 이 가중 평균을 매 스텝 계산하는 것, 그게 전부다.**

### 2.2 칼만 이득 — 가중치를 숫자 하나로

그 가중치에 이름이 붙어 있다. **칼만 이득(Kalman gain)** $K$는 0과 1 사이의 값이고, 최종 추정은 "예측에서 시작해 측정과의 차이(잔차)를 $K$만큼만 반영한다"는 식으로 쓰인다. $K$가 0에 가까우면 예측을 거의 그대로 믿고, $K$가 1에 가까우면 측정값을 거의 그대로 받아들인다. $K$ 자체는 예측의 불확실성과 측정의 불확실성의 비율로 정해지므로, 사람이 매초 손으로 가중치를 튜닝할 필요가 없다 — **불확실성이 스스로 가중치를 결정한다.**

한 사이클은 두 단계다.

**예측:** 운동 모델로 다음 상태를 밀어 본다. $\hat{x}^- = \hat{x} + v$ (등속 모델이면 속도만큼 전진). 이 예측에는 모델 자체의 오차 $Q$(바람, 바퀴 미끄러짐 같은 예측 못 한 변화)가 더해져 불확실성이 커진다. $P^- = P + Q$.

**보정:** 측정값이 도착하면 칼만 이득을 계산하고, 그 이득으로 예측을 끌어당긴다.

$$K = \frac{P^-}{P^- + R}, \qquad \hat{x} = \hat{x}^- + K(z - \hat{x}^-), \qquad P = (1 - K)P^-$$

세 식이 이 챕터가 다루는 전부다. 유도는 두 가우시안을 곱해 정규화하는 계산인데, 이 챕터는 그 전개를 건너뛴다 — **결과 식 세 개와, 그 식이 숫자에서 실제로 무엇을 하는지가 남아야 할 전부다.** 보정이 끝나면 분산 $P$는 항상 $P^-$보다 작아진다. 측정을 하나 더 본 것이므로 불확실성이 줄어드는 것은 당연하고, 이 식이 그것을 보장한다.

### 2.3 EKF — 직선이 아닌 곳에서는 접선을 쓴다

지금까지의 식은 운동과 측정이 전부 **덧셈과 상수배**로 표현될 때만 성립한다. 그래야 가우시안에 그 연산을 적용한 결과가 다시 가우시안이기 때문이다. 그런데 실제 센서는 종종 비선형이다. 레이더가 재는 것이 위치가 아니라 기준점까지의 거리라면 측정식은 $z = \sqrt{x^2 + y^2}$이고, 가우시안을 이 식에 통과시킨 결과는 더 이상 가우시안이 아니다. 위 세 식을 그대로 쓸 수 없다.

**확장 칼만 필터(EKF)의 답은 매 스텝 그 비선형 함수를 지금 추정치 근처에서 직선으로 근사하는 것이다.** 곡선 위의 한 점에서 접선을 그으면 그 점 아주 가까이에서는 접선과 곡선이 거의 겹친다 — 그 접선의 기울기가 **야코비안**이고, 스칼라에서는 단순히 미분값이다. 예를 들어 측정식이 $h(x) = x^2$이고 지금 추정치가 $\hat{x} = 3$이라면, 그 근방에서 $h$는 기울기 $H = h'(3) = 6$인 직선처럼 움직인다. 즉 $x$가 3에서 살짝 벗어나면 측정값은 그 여섯 배만큼 벗어난다. 이 기울기 $H$를 §2.2의 식에서 상수 1 자리에 넣으면 — $K = \frac{P^- H}{H^2 P^- + R}$, 나머지 갱신식은 형태가 그대로다 — 매 스텝 새로 근사된 직선에 대해 §2.2의 계산을 반복하는 것이 EKF다.

이 근사는 **딱 한 스텝짜리다.** 다음 스텝이 오면 새 추정치 근처에서 접선을 다시 긋는다. 추정치가 실제 곡선과 가까이 있는 동안은 접선이 곡선을 잘 따라가지만, 한 번 크게 어긋나면 접선의 기울기 자체가 틀린 방향을 가리키게 되고 필터가 실제 값에서 점점 멀어지며 발산할 수 있다. **EKF는 최적이라는 보장이 없다** — §2.2의 선형 칼만 필터는 조건(선형성 + 가우시안 잡음)을 만족하면 이론상 최선의 추정기임이 증명되지만, EKF는 근사 위에 근사를 쌓은 것이라 그 증명이 성립하지 않는다. 그런데도 실무에서 널리 쓰이는 이유는 계산이 여전히 §2.2와 같은 정도로 싸고, 비선형성이 심하지 않은 범위에서는 근사가 충분히 좋기 때문이다.

## 3. 손으로 따라가기

`K`는 `0.6689 → 0.4079 → 0.2997 → 0.2422 → 0.2078 → 0.1855`로 계속 줄어든다. `P`도 `0.3344`에서 `0.0928`까지 계속 줄지만 0에 닿지는 않는다 — 매 스텝 $Q = 0.01$이 다시 더해지므로 불확실성이 완전히 사라질 수는 없고, 어느 지점에서 $P$가 늘어나는 양(＋$Q$)과 측정으로 줄어드는 양이 균형을 이루는 **정상 상태**에 가까워진다.

`x`는 `0.8662, 1.7576, 2.9501, 3.8895, 4.9540, 5.9440`로 참값 `1, 2, 3, 4, 5, 6`에 스텝마다 더 가까이 붙는다. 첫 스텝의 오차는 `0.1338`이고 마지막 스텝의 오차는 `0.0560`이다. **필터가 개별 측정값보다 항상 더 정확하다는 뜻은 아니다** — GPS 원본값 `5.9`도 참값 `6`과 `0.1`밖에 안 틀렸다. 필터가 하는 일은 잡음을 없애는 것이 아니라, 매 순간 예측과 측정 중 어느 쪽이 더 믿을 만한지를 계산해 그 비율로 섞는 것이다.

$K$가 줄어드는 이유는 $P$가 줄기 때문이다. 로봇의 위치를 여러 번 관찰할수록 "지금 어디 있는지"에 대한 필터의 확신($P$가 작다)이 측정 하나의 확신($R = 0.5$, 고정)보다 점점 커지고, 그러면 새 측정 하나가 추정을 흔드는 힘이 상대적으로 작아진다. **자신감이 쌓일수록 새 증거 하나에 덜 흔들리는 것**이 이 수렴의 정체다.

## 4. 구현

::: dual
```python title="1차원 칼만 필터 — GPS 위치 추정"
def kalman_1d(z, x, P, v, Q, R):
    x_pred = x + v                      # 예측: 등속 모델로 한 스텝 전진
    P_pred = P + Q                      # 예측: 불확실성이 프로세스 잡음만큼 커진다
    K = P_pred / (P_pred + R)           # 칼만 이득: 예측과 측정 중 어느 쪽을 더 믿을지
    x = x_pred + K * (z - x_pred)       # 보정: 잔차(z - x_pred)를 이득만큼 반영
    P = (1 - K) * P_pred                # 보정: 반영한 만큼 불확실성이 줄어든다
    return x, P, K, x_pred, P_pred


Q, R, v = 0.01, 0.5, 1.0
x, P = 0.0, 1.0                         # 초기 추정과 초기 불확실성
zs = [0.8, 1.6, 3.4, 3.7, 5.2, 5.9]     # 잡음 섞인 위치 측정값 (참값은 1,2,3,4,5,6)

for step, z in enumerate(zs):
    x, P, K, x_pred, P_pred = kalman_1d(z, x, P, v, Q, R)
    print(f"step={step} z={z:.1f} x_pred={x_pred:.4f} P_pred={P_pred:.4f} "
          f"K={K:.4f} x={x:.4f} P={P:.4f}")
```
```cpp title="1차원 칼만 필터 — GPS 위치 추정"
#include <cstdio>
#include <tuple>
#include <vector>
using namespace std;

tuple<double, double, double, double, double> kalman_1d(double z, double x, double P, double v, double Q, double R) {
    double x_pred = x + v;              // 예측: 등속 모델로 한 스텝 전진
    double P_pred = P + Q;              // 예측: 불확실성이 프로세스 잡음만큼 커진다
    double K = P_pred / (P_pred + R);   // 칼만 이득: 예측과 측정 중 어느 쪽을 더 믿을지
    x = x_pred + K * (z - x_pred);      // 보정: 잔차(z - x_pred)를 이득만큼 반영
    P = (1 - K) * P_pred;               // 보정: 반영한 만큼 불확실성이 줄어든다
    return {x, P, K, x_pred, P_pred};
}

int main() {
    double Q = 0.01, R = 0.5, v = 1.0;
    double x = 0.0, P = 1.0;                             // 초기 추정과 초기 불확실성
    vector<double> zs = {0.8, 1.6, 3.4, 3.7, 5.2, 5.9};   // 잡음 섞인 위치 측정값 (참값은 1,2,3,4,5,6)

    for (size_t step = 0; step < zs.size(); step++) {
        double z = zs[step];
        auto [nx, nP, K, x_pred, P_pred] = kalman_1d(z, x, P, v, Q, R);
        x = nx; P = nP;
        printf("step=%zu z=%.1f x_pred=%.4f P_pred=%.4f K=%.4f x=%.4f P=%.4f\n",
               step, z, x_pred, P_pred, K, x, P);
    }
}
```

**복잡도:** 시간 $O(1)$ 매 스텝 — 덧셈·곱셈·나눗셈이 상수 번이고, 측정 하나를 처리하는 데 이전 상태 두 숫자($\hat{x}$, $P$)만 있으면 된다(과거 측정을 다시 훑지 않는다). 공간 $O(1)$ — 그 두 숫자만 유지한다. 상태가 스칼라가 아니라 $d$차원 벡터인 일반형에서는 이 식들이 행렬 연산이 되고, $K$를 구하는 데 $d \times d$ 행렬의 역행렬이 필요해 시간이 $O(d^3)$으로 뛴다. 이 챕터는 그 일반형을 다루지 않는다 — 스칼라 하나로 칼만 이득이 하는 일을 정확히 보이는 것이 목표이고, 벡터·행렬 표기는 이 직관 위에 문자만 얹는 일이다.

| 언어 차이 | Python | C++ |
|---|---|---|
| 다중 반환값 | 튜플 `return x, P, K, x_pred, P_pred`을 언패킹으로 그대로 받는다 | `std::tuple`을 반환하고 구조적 바인딩(`auto [nx, nP, ...]`)으로 받는다 — C++17 문법 |
| 부동소수 서식 | f-string `{:.4f}` | `printf`의 `%.4f`. 형태만 다르고 반올림 규칙은 같다(양쪽 다 IEEE 754 배정밀도) |
| 반복 대상 | `enumerate(zs)`가 인덱스와 값을 함께 준다 | 인덱스를 직접 돌리고 `zs[step]`으로 값을 꺼낸다 |

::: pitfall
- **$Q$와 $R$을 실제 잡음과 다르게 설정한다.** $R$을 실제보다 작게 잡으면 필터가 측정값을 과신해 다시 떨리기 시작하고, $Q$를 실제보다 작게 잡으면 필터가 자기 예측을 과신해 실제 움직임을 따라가지 못하고 뒤처진다. 두 숫자는 센서 스펙과 운동 모델의 불확실성에서 나오는 값이지 임의로 줄여도 되는 튜닝 손잡이가 아니다.
- **$P$가 음수가 되도록 방치한다.** 부동소수 반올림이 누적되면 $(1-K)P^-$가 이론상 항상 양수인데도 계산상 음수로 떨어지는 경우가 실제로 있다. 이 챕터의 형태(Joseph form이 아닌 단순 형태)는 그 위험에 특히 취약하다 — 장시간 도는 필터에서는 $P$가 음수가 되지 않는지 매 스텝 확인하는 방어 코드가 필요하다.
- **EKF의 야코비안을 초기 추정치에서 딱 한 번만 계산하고 고정한다.** 야코비안은 **그 스텝의 현재 추정치에서 매번 다시 계산**해야 하는 값이다. 고정하면 추정치가 움직인 뒤에는 전혀 다른 곡선의 접선을 계속 쓰는 셈이 된다.
- **비선형성이 심한 구간에서 EKF가 발산하는데 원인을 잡음 파라미터 탓으로 돌린다.** $Q$, $R$을 아무리 조정해도 선형화 오차 자체는 줄지 않는다. 이 경우가 [XIII-4 파티클 필터](#/xiii-4)로 넘어가야 하는 신호다.
:::

## 5. 어디에 쓰이는가

**GPS와 IMU의 센서 퓨전이 이 챕터의 가장 흔한 실사례다.** GPS는 절대 위치를 주지만 갱신이 느리고(초당 몇 회) 도심에서는 건물에 반사되어 잡음이 커진다. IMU(가속도계·자이로)는 매우 빠르게(초당 수백~수천 회) 갱신되지만 적분 오차가 누적되어 시간이 지날수록 절대 위치에서 벗어난다. 칼만 필터는 IMU로 매 스텝 **예측**하고 GPS가 도착할 때만 **보정**하는 구조로 이 둘을 하나의 추정치로 합친다 — 드론과 자율주행차의 위치 추정 스택에서 예외 없이 나타나는 조합이다. 회전이 섞이면 예측·측정식이 비선형이 되어 EKF로 넘어간다.

::: interview
**"칼만 필터가 최적이라는 것은 무슨 뜻입니까."** 조건 세 가지를 답한다 — 시스템이 선형이고, 잡음이 가우시안이고, 잡음의 평균과 분산($Q$, $R$)을 정확히 안다. 이 조건에서 칼만 필터는 평균제곱오차를 최소화하는 추정기임이 증명된다. 세 조건 중 하나라도 깨지면(비선형이면 EKF, 잡음이 다봉분포면 파티클 필터로) 그 증명이 더는 성립하지 않는다.

**"칼만 이득이 하는 일을 한 문장으로 설명해 보세요."** "예측과 측정 중 어느 쪽이 더 믿을 만한지를 두 불확실성의 비율로 계산해, 그 비율만큼만 예측을 측정 쪽으로 끌어당깁니다." $K \to 0$이면 예측만 믿고, $K \to 1$이면 측정만 믿는다는 양 극단을 짚으면 답이 완결된다.

**"EKF는 왜 최적이 아닙니까."** 선형 칼만 필터의 최적성 증명은 가우시안에 선형 변환을 적용한 결과가 다시 정확히 가우시안이라는 사실에 기댄다. EKF는 비선형 함수를 매 스텝 접선으로 근사하므로 그 결과는 근사적으로만 가우시안이고, 근사 오차가 스텝마다 쌓일 수 있다. "동작은 하지만 증명은 없다"는 것이 정확한 답이다.
:::

## 연습

::: quiz
칼만 필터·EKF는 코딩테스트의 원형 문제가 거의 없는 영역이다. 대신 상황을 주고 **① 무엇이 예측이고 무엇이 측정인가 ② 가우시안 가정이 성립하는가 ③ 성립하지 않으면 무엇이 필요한가**를 판단한다.

**1. 실내 온도 추정**
- 상황: 온도 센서 하나가 1분마다 값을 읽는데 ±0.3도 잡음이 섞인다. 난방 시스템의 목표 온도와 최근 변화율로 다음 값을 예측할 수 있다.
- 판단: 운동 모델(변화율 기반 예측)과 측정(센서값)이 둘 다 덧셈·상수배로 표현되고, 잡음이 대칭적인 하나의 봉우리로 보인다. 선형 칼만 필터가 그대로 들어맞는 사례다.

**2. 벽에 붙은 거리 센서로 방 안 위치 추정**
- 상황: 로봇이 초음파 센서로 가장 가까운 벽까지의 거리를 잰다. 방이 직사각형이라 로봇이 정중앙에 있으면 네 벽 중 어느 쪽이 가장 가까운지 애매하고, 대칭 위치 여러 곳에서 같은 거리값이 나온다.
- 판단: 측정 하나가 "위치가 A이거나 B이거나 C"라는 **여러 개의 분리된 가능성**을 가리킨다. 가우시안 하나로는 이 상황을 표현할 수 없다 — 봉우리 여러 개의 평균을 내면 그 사이의, 로봇이 있을 수 없는 지점이 나온다. [XIII-4 파티클 필터](#/xiii-4)로 가야 하는 신호다.

**3. 회전하는 팔의 끝점 위치를 카메라로 추정**
- 상황: 관절 각도 센서로 팔의 움직임을 예측하고, 카메라가 끝점의 화면 좌표를 측정한다. 각도에서 화면 좌표로 가는 변환에 삼각함수가 들어간다.
- 판단: 측정식이 비선형(삼각함수)이지만 각 스텝의 오차가 작고 봉우리는 하나뿐이다. 매 스텝 현재 추정치에서 야코비안을 다시 계산하는 EKF가 표준적인 선택이다.
:::

## 요약

- GPS 값을 그대로 쓰면 떨리고, 단순 평균을 쓰면 뒤처진다. 칼만 필터는 예측과 측정을 **각자의 불확실성 비율로 가중 평균**해 둘의 장점만 취한다.
- 상태를 평균과 분산 두 숫자짜리 가우시안 하나로 못박는 것이 칼만 필터의 정의다. [XIII-2](#/xiii-2)가 열어 둔 "분포를 어떻게 표현할까"의 빈칸을 여기서 채운다.
- 칼만 이득 $K = P^-/(P^- + R)$이 가중치다. 예측 불확실성 $P^-$가 크면 측정 쪽으로, 측정 잡음 $R$이 크면 예측 쪽으로 붙는다.
- 보정 갱신은 $\hat{x} = \hat{x}^- + K(z - \hat{x}^-)$, $P = (1-K)P^-$ 두 식뿐이다. 스텝을 거듭할수록 $P$와 $K$는 함께 줄어 정상 상태로 수렴한다.
- EKF는 비선형 운동·측정식을 **매 스텝 현재 추정치에서의 접선(야코비안)**으로 근사해 같은 세 식을 재사용한다. 근사이므로 최적성 증명이 없고, 추정치가 크게 벗어나면 발산할 수 있다.
- 칼만 필터·EKF는 분포가 봉우리 하나(단봉)이고 대체로 매끄러울 때만 통한다. 봉우리가 여러 개로 갈라지면 이 틀 자체가 깨진다.
