# XIII-4 파티클 필터

::: lead
"내가 어디 있는지"에 대한 답이 하나의 봉우리가 아니라 여러 개로 갈라져 있을 때, 그 믿음을 무엇으로 표현하는가.
:::

## 1. 문제

로봇이 똑같이 생긴 문이 5미터 간격으로 늘어선 긴 복도에 놓였다. 처음에는 자기가 어디 있는지 전혀 모른다. 라이다가 "지금 바로 옆에 문이 있다"고 알려 준다.

이 측정 하나가 로봇의 위치를 하나로 좁혀 주지 않는다. 문이 다섯 개면 로봇은 다섯 군데 중 어느 한 곳에 있을 수 있고, 그 다섯 곳은 서로 멀리 떨어져 있다. [XIII-3 칼만 필터와 EKF](#/xiii-3)의 방식대로 이 상황을 가우시안 하나(평균, 분산)로 표현하면 어떻게 되는가. 다섯 문의 위치를 평균 내면 복도 한가운데 어딘가가 나온다 — **로봇이 실제로 있을 수 없는 지점**이다. 분산을 아무리 키워도 "다섯 개의 분리된 가능성"이라는 사실 자체를 가우시안 하나로는 표현할 방법이 없다. 봉우리가 하나가 아니라 여러 개인 분포를 **다봉분포(multi-modal distribution)**라 부르고, 칼만 필터 계열은 정의상 이 상황을 다루지 못한다.

로봇이 몇 걸음 더 걸어 두 번째 문을 만나면 상황이 달라진다. "이전 문에서 정확히 5미터 이동한 뒤에 다시 문을 만났다"는 조건을 만족하는 위치만 후보로 남고, 처음에는 다섯 갈래였던 가능성이 하나(또는 복도 끝이라 더 적은 수)로 좁혀진다. 이런 좁혀짐은 **분포의 모양이 통째로 바뀌는 과정**이고, 그 모양은 문의 배치와 로봇이 지나온 경로에 따라 매번 달라진다. 고정된 수식 하나로 미리 정해 둘 수 있는 형태가 아니다.

[XIII-2 베이즈 필터의 뼈대](#/xiii-2)가 세운 예측-보정 틀은 그대로 유효하다. [XIII-3](#/xiii-3)은 그 틀에서 분포의 형태를 가우시안 하나로 고정하는 선택을 했다. 이 챕터는 정반대의 선택을 한다 — **분포의 형태를 아예 고정하지 않고, 수많은 구체적인 가설들의 집합으로 분포 그 자체를 표현한다.**

## 2. 아이디어

### 2.1 분포를 수식이 아니라 샘플 뭉치로 표현한다

파티클 필터는 로봇의 위치에 대한 믿음을 하나의 수식이 아니라 **파티클(particle)이라 부르는 수천 개의 구체적인 가설**로 표현한다. 파티클 하나는 "로봇이 지금 이 지점에, 이 방향을 보고 있다"는 완전한 상태 하나와, 그 가설이 얼마나 그럴듯한지를 나타내는 **가중치** 하나로 이루어진다. 로봇이 복도 어딘가에 있다는 것만 아는 초기 상태라면, 파티클들을 복도 전체에 고르게 흩뿌려 표현한다. 문 다섯 개 근처에 후보가 몰려 있는 상태라면, 파티클 다섯 뭉치가 각 문 근처에 몰려 있는 형태로 그 상황이 자연스럽게 나타난다 — **다봉분포를 표현하기 위해 특별한 장치가 필요 없다. 파티클이 알아서 여러 군데에 몰려 있으면 그것이 곧 다봉분포다.**

### 2.2 예측 — 각 파티클을 각자 밀어 본다

로봇이 한 걸음 움직이면 파티클 하나하나에 그 움직임과 약간의 잡음을 더해 새 위치로 옮긴다. 잡음을 더하는 이유는 실제 이동에 오차가 있기 때문이고, 그 오차만큼 파티클들이 흩어져야 다음 측정에서 정확한 후보가 선택될 여지가 생긴다. 이 단계에 [XIII-3 §2.3](#/xiii-3)이 다룬 비선형 문제가 아예 등장하지 않는다는 것이 핵심이다. 운동 모델이 아무리 복잡한 비선형 함수여도 파티클 하나하나에 그 함수를 있는 그대로 적용하면 그만이다. **선형화도, 야코비안도 필요 없다** — 함수를 근사하는 대신 함수를 수천 번 그냥 계산한다.

### 2.3 가중치 — 측정과 얼마나 맞아떨어지는가

새 측정값이 들어오면 각 파티클의 위치에서 "이 측정값이 나올 가능성이 얼마나 되는가"를 계산해 그 값을 가중치로 준다. 문 근처에 있는 파티클은 "지금 문이 보인다"는 측정과 잘 맞아떨어지므로 높은 가중치를 받고, 복도 한가운데 있는 파티클은 낮은 가중치를 받는다. 이 계산도 측정식이 비선형이든 계산이 복잡하든 상관없다 — **파티클 하나에 대해 숫자 하나만 계산하면 된다.** 모든 파티클의 가중치를 계산한 뒤 합이 1이 되도록 정규화한다.

### 2.4 리샘플링 — 그럴듯한 가설만 남긴다

가중치를 매기는 것만으로는 부족하다. 시간이 지날수록 대부분의 파티클은 가중치가 0에 가까워지고 극소수만 의미 있는 가중치를 갖는다 — 이 현상을 **퇴화(degeneracy)**라 부른다. 가중치가 0에 가까운 파티클 수천 개를 계속 들고 다니는 것은 계산 낭비이고, 더 나쁘게는 다음 예측 단계에서 그 쓸모없는 가설들 주변을 계속 탐색하느라 정말 그럴듯한 가설 주변은 충분히 탐색하지 못한다.

**리샘플링은 가중치에 비례해서 새 파티클 집합을 다시 뽑는 것이다.** 가중치가 큰 파티클은 여러 번 복제되고, 가중치가 작은 파티클은 사라진다. 뽑고 난 뒤 모든 파티클의 가중치는 다시 균등하게(1/N) 초기화된다 — 정보는 "어디에 파티클이 몇 개나 몰려 있는가"라는 **밀도**로 옮겨 갔기 때문이다.

가장 단순한 방법은 가중치를 확률로 보고 매번 독립적으로 N번 뽑는 것(다항 리샘플링)인데, 이 방법은 뽑을 때마다 난수를 하나씩 쓰므로 우연히 한쪽으로 쏠릴 수 있다(분산이 크다). **시스테매틱 리샘플링(systematic resampling)**은 난수를 딱 하나만 뽑아 시작점으로 삼고, 그 뒤로는 $1/N$ 간격의 등간격 점들을 누적 가중치 위에 순서대로 찍는다. 등간격이므로 큰 가중치 구간에는 자연히 점이 여러 개 떨어지고 작은 가중치 구간에는 점이 하나도 안 떨어질 수 있다 — 그 결과가 "가중치에 비례한 복제"다. 난수를 하나만 쓰므로 뽑기 사이의 우연한 쏠림이 없고, 구현도 누적합을 한 번 훑는 선형 스캔이라 다항 리샘플링보다 빠르다.

::: note
**언제 리샘플링을 할지도 선택이다.** 매 스텝 리샘플링하면 복제가 반복되어 서로 다른 파티클들이 결국 몇 개의 가계로 수렴해 버리는 **파티클 고갈(particle deprivation)**이 빨라진다. 실무 구현은 유효 샘플 크기(effective sample size, 가중치가 얼마나 고르게 퍼져 있는지를 재는 지표)가 임계값 밑으로 떨어질 때만 리샘플링한다. 이 챕터는 "매 스텝 리샘플링한다"는 가장 단순한 판을 다룬다.
:::

## 3. 손으로 따라가기

::: trace
파티클 다섯 개가 각각 위치 `2.0, 4.0, 4.5, 7.0, 9.0`에 있다. 측정값 `z = 4.3`이 들어온다. 가중치는 $w_i = \exp\left(-\dfrac{(x_i - z)^2}{2\sigma^2}\right)$, $\sigma = 1.0$으로 계산한 뒤 합이 1이 되도록 정규화한다.

|---|---|---|---|
| 0 | 2.0 | 0.0349 | 0.0349 |
| 1 | 4.0 | 0.4702 | 0.5051 |
| 2 | 4.5 |  |  |
| 3 | 7.0 |  |  |
| 4 | 9.0 |  |  |

시스테매틱 리샘플링: 시작점 $u_0 = 0.1$, 이후 점은 $u_j = u_0 + j/5$ ($j = 0, 1, 2, 3, 4$)이므로 `0.1, 0.3, 0.5, 0.7, 0.9`. 각 점 $u_j$에 대해, 누적 가중치가 $u_j$ 이상이 되는 **첫 파티클**을 선택한다.

세 가지를 확인하라.

- [ ] 파티클 4(위치 9.0)의 가중치가 사실상 0인 이유. $z = 4.3$과 얼마나 멀리 떨어져 있는지 본다
- [ ] 다섯 개의 점 `0.1, 0.3, 0.5, 0.7, 0.9`가 각각 어느 파티클에 떨어지는지, 누적 가중치 열을 보고 채운다
- [ ] 리샘플링 뒤 파티클 0(위치 2.0)과 파티클 4(위치 9.0)가 새 집합에 몇 개 남는지
:::

시스테매틱 리샘플링의 점 `0.1, 0.3, 0.5, 0.7, 0.9`를 누적 가중치 열에 대조한다.

| 점 $u_j$ | 누적 가중치가 처음 $u_j$ 이상이 되는 파티클 | 선택된 위치 |
|---|---|---|
| 0.1 | 파티클 1 (누적 0.5051) | 4.0 |
| 0.3 | 파티클 1 (누적 0.5051) | 4.0 |
| 0.5 | 파티클 1 (누적 0.5051) | 4.0 |
| 0.7 | 파티클 2 (누적 0.9871) | 4.5 |
| 0.9 | 파티클 2 (누적 0.9871) | 4.5 |

새 파티클 집합은 `4.0, 4.0, 4.0, 4.5, 4.5`다. 가중치가 거의 0이던 파티클 0(2.0)과 파티클 4(9.0)는 새 집합에 **한 개도 남지 않는다.** 가중치가 컸던 파티클 1(4.0)은 세 개로, 파티클 2(4.5)는 두 개로 늘었다 — 정확히 정규화 가중치 `0.4702`와 `0.4821`의 비율(5개 중 약 2.35개 대 2.41개)에 가장 가깝게 반올림된 결과다.

측정값이 `4.3`이었고 새 집합이 `4.0`과 `4.5` 주변에 몰렸다는 것에 주목하라. **리샘플링이 끝나면 파티클 뭉치의 위치 자체가 다음 스텝의 추정치를 대신한다** — 이 예제처럼 파티클이 한 군데로 모이면 사실상 하나의 값으로 수렴한 것이고, 애초에 다섯 문 근처에 다섯 뭉치가 남아 있었다면 그 상태 그대로가 "다섯 가지 가능성이 아직 다 살아 있다"는 뜻이다. 가우시안이었다면 표현할 수 없었던 상태가 파티클 집합에서는 그냥 파티클들이 몰려 있는 모양으로 자연스럽게 나타난다.

## 4. 구현

::: dual
```python title="파티클 가중치 계산과 시스테매틱 리샘플링"
import math


def gaussian_weight(x, z, sigma):
    return math.exp(-((x - z) ** 2) / (2 * sigma ** 2))


def systematic_resample(cum_weights, u0, n):
    indices = []
    i = 0
    for j in range(n):
        u = u0 + j / n
        while cum_weights[i] < u:        # 누적 가중치가 u를 넘어설 때까지 스캔
            i += 1
        indices.append(i)
    return indices


xs = [2.0, 4.0, 4.5, 7.0, 9.0]      # 파티클의 위치(가설)
z = 4.3                             # 이번 측정값
sigma = 1.0                         # 측정 잡음의 표준편차

raw = [gaussian_weight(x, z, sigma) for x in xs]
total = sum(raw)
weights = [w / total for w in raw]  # 정규화: 합이 1이 되게

cum = []
acc = 0.0
for w in weights:
    acc += w
    cum.append(acc)

for x, w, c in zip(xs, weights, cum):
    print(f"x={x:.1f} weight={w:.4f} cum={c:.4f}")

N = len(xs)
u0 = 0.1                            # 리샘플링 시작 오프셋 — [0, 1/N) 안의 값 하나면 된다
indices = systematic_resample(cum, u0, N)
resampled = [xs[i] for i in indices]
print("resampled indices =", indices)
print("resampled x       =", resampled)
```
```cpp title="파티클 가중치 계산과 시스테매틱 리샘플링"
#include <cmath>
#include <cstdio>
#include <string>
#include <vector>
using namespace std;

double gaussian_weight(double x, double z, double sigma) {
    return exp(-((x - z) * (x - z)) / (2 * sigma * sigma));
}

vector<int> systematic_resample(const vector<double>& cum_weights, double u0, int n) {
    vector<int> indices;
    int i = 0;
    for (int j = 0; j < n; j++) {
        double u = u0 + (double)j / n;
        while (cum_weights[i] < u) i++;   // 누적 가중치가 u를 넘어설 때까지 스캔
        indices.push_back(i);
    }
    return indices;
}

int main() {
    vector<double> xs = {2.0, 4.0, 4.5, 7.0, 9.0};   // 파티클의 위치(가설)
    double z = 4.3;                                   // 이번 측정값
    double sigma = 1.0;                                // 측정 잡음의 표준편차

    vector<double> raw;
    for (double x : xs) raw.push_back(gaussian_weight(x, z, sigma));
    double total = 0.0;
    for (double r : raw) total += r;
    vector<double> weights;
    for (double r : raw) weights.push_back(r / total);  // 정규화: 합이 1이 되게

    vector<double> cum;
    double acc = 0.0;
    for (double w : weights) {
        acc += w;
        cum.push_back(acc);
    }

    for (size_t k = 0; k < xs.size(); k++)
        printf("x=%.1f weight=%.4f cum=%.4f\n", xs[k], weights[k], cum[k]);

    int N = (int)xs.size();
    double u0 = 0.1;   // 리샘플링 시작 오프셋 — [0, 1/N) 안의 값 하나면 된다
    vector<int> indices = systematic_resample(cum, u0, N);

    string idx_str = "[";
    string x_str = "[";
    for (size_t k = 0; k < indices.size(); k++) {
        if (k) { idx_str += ", "; x_str += ", "; }
        idx_str += to_string(indices[k]);
        char buf[16];
        snprintf(buf, sizeof(buf), "%.1f", xs[indices[k]]);
        x_str += buf;
    }
    idx_str += "]";
    x_str += "]";
    printf("resampled indices = %s\n", idx_str.c_str());
    printf("resampled x       = %s\n", x_str.c_str());
}
```

```console
resampled x       = [4.0, 4.0, 4.0, 4.5, 4.5]
```

**복잡도:** 시간 $O(N)$ — 가중치 계산이 파티클마다 상수 시간이라 $O(N)$, 정규화·누적합도 각각 $N$개를 한 번씩 훑어 $O(N)$, 시스테매틱 리샘플링의 인덱스 포인터 `i`는 전체 스캔에서 앞으로만 움직이므로 $N$개의 점을 찾는 데 총 $O(N)$이다(각 점마다 다시 처음부터 찾지 않는다). 합쳐서 $O(N)$ — 다항 리샘플링이 뽑을 때마다 이진 탐색을 쓰면 $O(N \log N)$인 것과 대비된다. 공간 $O(N)$ — 파티클 위치·가중치·누적합 배열을 각각 하나씩 든다.

| 언어 차이 | Python | C++ |
|---|---|---|
| 리스트 컴프리헨션 | `[gaussian_weight(x, z, sigma) for x in xs]` | 반복문으로 직접 `push_back` |
| 리스트를 그대로 출력 | `print("resampled x =", resampled)`가 `[4.0, 4.0, ...]` 형태를 자동으로 만든다 | 컨테이너에 기본 문자열 표현이 없어 `idx_str`/`x_str`를 직접 조립해야 한다 — [XV-11](#/xv-11)의 `log_str` 헬퍼와 같은 이유다 |
| 부동소수 서식 | f-string `{:.4f}`, `{:.1f}` | `printf`/`snprintf`의 `%.4f`, `%.1f`. 반올림 규칙은 동일(IEEE 754 배정밀도) |

::: pitfall
- **파티클 수를 상태 차원과 무관하게 고정한다.** 상태가 2차원(위치 x, y)이면 같은 밀도로 공간을 덮는 데 필요한 파티클 수가 1차원일 때보다 훨씬 많아지고, 3차원·6차원(위치+자세)으로 갈수록 필요한 개수가 기하급수적으로 늘어난다 — **차원의 저주**가 파티클 필터의 실질적인 한계다. 실무에서 파티클 필터가 로봇의 2D 평면 위치·방향(3차원)까지만 흔히 쓰이고 그 이상 확장하지 않는 이유다.
- **가중치 정규화를 빼먹는다.** $z = \exp(-(x-z)^2/2\sigma^2)$ 값 자체는 합이 1이 아니다. 정규화를 빼먹으면 누적합이 1을 넘거나 못 미쳐 시스테매틱 리샘플링의 등간격 점들이 마지막 파티클에 도달하지 못하고 배열 밖을 읽는다.
- **매 스텝 무조건 리샘플링한다.** §2.4의 note대로 매번 리샘플링하면 파티클 고갈이 빨라진다. 실무 구현은 유효 샘플 크기를 재서 필요할 때만 리샘플링한다.
- **모든 측정에서 모든 가중치가 0에 가깝게 나온다.** 파티클이 실제 로봇 위치 근처에 하나도 없으면(초기 분포가 너무 좁았거나 로봇이 순간이동하듯 튀었을 때) 벌어진다. 대응책은 매 스텝 파티클의 일부를 무작위 위치에서 새로 주입하는 것이다(로봇 유괴 문제의 표준 대응).
:::

## 5. 어디에 쓰이는가

**AMCL(Adaptive Monte Carlo Localization)이 이 챕터를 그대로 구현한 것이다.** 지도가 이미 있는 상태에서 로봇이 그 지도 위 어디에 있는지 찾는 문제를 로봇 내비게이션 스택(ROS의 Nav2 등)이 이 방식으로 푼다. 처음 켰을 때(전역 위치를 전혀 모를 때) 파티클을 지도 전체에 흩뿌리고, 라이다 스캔이 지도와 맞아떨어지는 정도로 가중치를 매기며, 로봇이 움직이고 관측을 반복할수록 파티클이 실제 위치 주변으로 좁혀진다. "로봇이 누군가에 의해 갑자기 다른 곳으로 옮겨졌다"(유괴 문제)는 상황도 파티클 일부를 계속 무작위로 재주입하는 방식으로 같은 틀 안에서 대응한다.

::: interview
**"파티클 필터와 칼만 필터의 근본적인 차이가 무엇입니까."** 표현 방식의 차이라고 답한다. 칼만 필터는 분포의 형태를 가우시안으로 고정하고 그 두 모수(평균, 분산)를 계산으로 갱신한다. 파티클 필터는 형태를 고정하지 않고 샘플들의 밀도로 분포를 근사한다 — 그래서 다봉분포, 비선형 운동·측정 모두 특별한 처리 없이 다룰 수 있지만, 그 대가로 파티클 수가 부족하면 근사 자체가 부정확해진다.

**"파티클을 몇 개나 써야 합니까."** 정해진 답이 없다는 것이 정답의 일부다. 상태 차원, 분포가 얼마나 넓게 퍼져 있는지, 요구되는 정확도에 따라 다르다. 실무적인 답변 뼈대는 "유효 샘플 크기를 관찰하면서 필요한 만큼 늘리고, 계산 예산(제어 주기 안에 끝나야 한다는 제약)이 상한을 정한다"이다.

**"리샘플링을 왜 매번 하지 않고 조건부로 합니까."** 매번 하면 다양성이 줄어드는 파티클 고갈이 빨라진다는 것이 핵심이고, 그 판단 기준으로 유효 샘플 크기를 언급하면 답이 완결된다.
:::

## 연습

::: quiz
파티클 필터도 코딩테스트 원형 문제가 거의 없다. [XIII-3의 연습](#/xiii-3)과 이어지는 상황들로 **어떤 필터가 맞는지, 그 근거가 무엇인지**를 판단한다.

**1. 창고 로봇의 전원이 나갔다가 다시 켜졌다**
- 상황: 로봇이 창고 안 어딘가에 있는데, 꺼지기 전 위치를 신뢰할 수 없다(사람이 옮겼을 수도 있다). 라이다 스캔 한 번으로 지도 전체에서 위치를 다시 찾아야 한다.
- 판단: 초기 믿음이 "지도 전체에 걸쳐 균등"이라는 극단적인 다봉분포이고, 정답 위치 근처에 조금이라도 확신을 가진 시작점이 없다. 가우시안 기반 필터는 애초에 시작할 평균조차 정할 수 없다. 파티클을 지도 전체에 흩뿌려 시작하는 파티클 필터의 전역 위치추정(global localization)이 표준 대응이다.

**2. 그 로봇이 위치를 찾은 뒤, 평평한 바닥에서 계속 주행한다**
- 상황: 위치가 이미 좁혀졌고, 매 스텝 바퀴 오도메트리로 예측하고 라이다로 보정한다. 분포는 하나의 봉우리 주변에서 계속 좁게 유지된다.
- 판단: 봉우리가 하나로 안정된 뒤에는 파티클 수천 개를 계속 유지하는 비용이 낭비다. 이 구간에서는 EKF로 전환해도 손실이 거의 없다 — 실제 AMCL도 내부적으로 파티클 수를 상황에 따라 동적으로 줄인다.

**3. 배가 GPS 신호가 약한 해역에서 소나로 해저 지형을 보며 위치를 추정한다**
- 상황: 해저 지형이 반복되는 굴곡을 가져서, 소나 측정 하나가 여러 개의 후보 위치와 맞아떨어진다. 배가 계속 이동하면서 후보가 점점 좁혀진다.
- 판단: 지형 반복으로 인한 다봉분포이면서 시간에 따라 후보가 좁혀지는 동적 과정이다 — 이 챕터 도입부의 문 복도 문제와 구조가 같다. 파티클 필터가 맞고, 소나-지형 대조 자체가 §2.3의 가중치 계산에 해당한다.
:::

## 요약

- 믿음이 여러 개의 분리된 가능성(다봉분포)으로 갈라지면 가우시안 하나로는 표현이 안 된다. 파티클 필터는 분포의 형태를 고정하지 않고 **샘플들의 뭉치**로 표현한다.
- 예측은 각 파티클에 운동 모델과 잡음을 개별로 적용한다. 비선형 함수를 그대로 적용하면 되므로 [XIII-3](#/xiii-3)의 야코비안·선형화가 필요 없다.
- 가중치는 각 파티클이 측정값과 얼마나 맞아떨어지는지를 나타낸다. 시간이 지날수록 소수의 파티클에 가중치가 몰리는 **퇴화**가 일어난다.
- 리샘플링은 가중치에 비례해 새 파티클 집합을 뽑고 가중치를 다시 균등하게 만든다. **시스테매틱 리샘플링**은 난수 하나 + 등간격 점으로 $O(N)$에 낮은 분산으로 이 일을 한다.
- 대가는 차원이다. 상태 차원이 늘수록 같은 밀도를 유지하는 데 필요한 파티클 수가 기하급수적으로 늘어난다.
- AMCL이 이 챕터를 그대로 구현한 대표 사례다 — 전역 위치추정과 유괴 로봇 문제 모두 파티클을 흩뿌리고 다시 모으는 같은 메커니즘으로 대응한다.
