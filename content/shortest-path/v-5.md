## 1. 문제

$201 \times 201$ 격자가 있다. 벽은 없고, 시작은 왼쪽 가운데 `(100, 0)`, 목표는 오른쪽 가운데 `(100, 200)`이다. 최단 거리는 200이고 경로는 가운데 행을 따라 곧게 가면 된다.

[V-1](#/v-1)의 다익스트라를 그대로 돌리면 **30,201칸을 확장한 뒤에야** 목표를 확정한다. 전체 40,401칸의 4분의 3이다. 목표는 정확히 오른쪽에 있는데 왼쪽 끝까지, 위쪽 끝까지, 아래쪽 끝까지 똑같이 번진다(측정 표는 §4.2에 있다).

이유는 알고리즘에 있지 않고 **알고리즘이 받는 정보에 있다.** V-1의 함수 시그니처를 보라. 인자는 그래프와 시작점뿐이다. 목표는 아예 넘어가지 않는다. 목표를 모르는 절차가 목표 쪽을 우대할 방법은 없다. 다익스트라는 "시작점에서 가까운 순서로 전부"를 구하는 알고리즘이고, 목표 하나를 원할 때도 그 전부를 구해 버린다.

한 대의 로봇이라면 이 낭비를 참을 수 있다. 초당 수십 번 경로를 다시 뽑아야 하거나([V-7](#/v-7)), 수백 대가 같은 지도를 공유하거나([V-9](#/v-9)), 지도가 도로망 규모로 커지면 못 참는다. **확장한 칸 수가 곧 응답 시간이다.**

필요한 것은 하나다. **"이 칸이 목표에 얼마나 가까운가"를 우선순위에 반영하는 것.**

## 2. 아이디어

### 2.1 우선순위에 추정치를 더한다

지금까지의 계보는 열린 목록에서 **무엇을 꺼내는가**만 바꿔 왔다([IV-3](#/iv-3) §2.1).

```text nolines
   BFS        큐 앞에서 꺼낸다              모든 간선 비용이 1
   다익스트라  g 가 가장 작은 것             g = 시작점에서 여기까지 확정된 비용
   A*         g + h 가 가장 작은 것         h = 여기서 목표까지의 추정 비용
```

$g(n)$은 이미 아는 값이다. $h(n)$은 **아직 안 가 본 구간에 대한 추측**이다. 둘을 더한 $f(n) = g(n) + h(n)$은 "$n$을 지나가는 경로의 총비용 추정치"가 된다. A\*는 이 $f$가 가장 작은 칸부터 꺼낸다.

::: widget grid-search {"algos":["dijkstra","astar"],"rows":18,"cols":18,"walls":"rooms","start":[1,1],"goal":[16,16],"weights":"uniform","heuristic":"manhattan"}
:::

두 패널의 코드 차이는 우선순위 한 줄뿐인데 그림이 전혀 다르다. 다익스트라는 시작점을 중심으로 한 등고선이 고르게 퍼진다. A\*는 목표 쪽으로 쐐기처럼 뻗는다. 벽에 막히면 쐐기가 잠시 옆으로 퍼졌다가 문을 찾으면 다시 곧게 뻗는다. **두 패널이 찾아낸 경로의 길이는 같다.** 다른 것은 그 길이를 알아내기까지 펼친 칸의 수다.

### 2.2 다익스트라는 $h = 0$인 A\*다

$h$를 모든 칸에서 0으로 두면 $f(n) = g(n) + 0 = g(n)$이다. **$f$로 정렬하는 것과 $g$로 정렬하는 것이 같은 말이 된다.** 그 순간 A\*는 다익스트라다.

::: widget grid-search {"algos":["dijkstra","astar"],"rows":18,"cols":18,"walls":"rooms","start":[1,1],"goal":[16,16],"weights":"uniform","heuristic":"zero"}
:::

위 위젯은 §2.1과 모든 것이 같고 휴리스틱만 `zero`로 바꾼 것이다. 두 패널이 같은 칸을 같은 순서로 확장하고 카운터의 숫자도 같아진다. ==다익스트라와 A\*는 두 알고리즘이 아니다. 하나의 알고리즘에 $h$를 무엇으로 주느냐다.== §4의 코드가 확장 순서까지 같음을 실제로 확인한다.

이 등가성은 방향이 둘이다. A\*를 새로 배울 때는 "다익스트라의 우선순위에 $h$를 더한 것"으로 읽으면 되고, A\*가 이상하게 동작할 때는 "$h$를 0으로 두면 다익스트라가 되니 거기서부터 좁혀 들어가면" 된다. **디버깅 절차이기도 하다.**

### 2.3 답이 유지되려면 — admissible

$h$를 아무렇게나 주면 답이 틀린다. $h$가 실제보다 크면 좋은 경로를 뒤로 밀어내고 나쁜 경로를 먼저 꺼내기 때문이다.

**admissible(허용적).** 모든 정점 $n$에 대해 $h(n) \le h^*(n)$. 여기서 $h^*(n)$은 $n$에서 목표까지의 **진짜** 최소 비용이다. 즉 ==절대 과대평가하지 않는다.== 목표에서는 $h = 0$이다.

**허용적이면 A\*가 찾는 답은 최적이다.** 목표 $G$를 꺼내는 순간을 보자. 최적 비용을 $C^*$라 하고, 최적 경로 위에서 아직 열린 목록에 남아 있는 첫 정점을 $n$이라 하자. $n$ 앞의 정점들은 전부 닫혔고 각각 완화되었으므로 $g(n)$은 최적 경로의 그 지점까지의 비용과 같다. 그러면

$$f(n) = g(n) + h(n) \le g(n) + h^*(n) = C^*$$

이다. 그런데 A\*는 $G$를 $n$보다 먼저 꺼냈다. 힙은 $f$가 작은 것부터 내주므로 $f(G) \le f(n) \le C^*$이고, $h(G) = 0$이니 $f(G) = g(G)$다. 따라서 $g(G) \le C^*$다. 실제로 존재하는 경로의 비용이 최적보다 작을 수는 없으므로 $g(G) = C^*$다.

논증이 기댄 것은 딱 한 곳, $h(n) \le h^*(n)$이다. **과대평가가 한 번이라도 있으면 그 부등호가 뒤집히고 결론이 사라진다.** 속도를 위해 일부러 과대평가하는 기법이 [V-6](#/v-6)의 Weighted A\*이고, 그 대가로 최적성을 내놓는다.

전제가 하나 더 숨어 있다. 위 논증은 **닫힌 정점이 개선되면 다시 여는 구현**을 가정한다(§4.1). 닫으면 끝인 구현에서 같은 결론을 얻으려면 조건이 하나 더 필요하고, 그것이 다음 절이다.

### 2.4 다시 열지 않으려면 — consistent

허용성은 **답**을 보장하지 **일의 양**을 보장하지 않는다. 그것을 보장하는 것은 다른 조건이다.

**consistent(일관, monotone).** 모든 간선 $(u, v)$에 대해

$$h(u) \le w(u, v) + h(v), \qquad h(\text{목표}) = 0$$

삼각부등식이다. "$u$에서 곧장 목표로 가는 추정치"가 "$u \to v$로 한 발 간 뒤 $v$에서 목표로 가는 추정치"보다 크면 안 된다.

일관하면 허용적이다. 목표까지의 최적 경로를 따라 위 부등식을 이어 붙이면 $h(n) \le h^*(n)$이 나온다. **반대는 성립하지 않는다. 이 구분이 이 절의 본론이다.**

일관성이 주는 것은 이것이다. 간선을 따라 $f$가 줄지 않는다.

$$f(v) = g(u) + w(u,v) + h(v) \ge g(u) + h(u) = f(u)$$

$f$가 비감소이면 힙에서 꺼내는 $f$의 순서가 비내림차순이고, 그러면 **정점을 꺼내는 순간 그 $g$는 이미 최적이다.** 나중에 더 짧은 경로가 발견되는 일이 없다. 닫은 정점을 다시 열 필요가 없다는 뜻이고, 이것은 [IV-3](#/iv-3)의 BFS가 "처음 찍는 값이 곧 최단"이었던 성질과 정확히 같은 구조다.

::: deep
일관성을 다르게 읽으면 이렇게 된다. 간선 비용을 다음처럼 재조정한다.

$$w'(u, v) = w(u, v) + h(v) - h(u)$$

일관성은 정확히 **모든 $w'$가 음수가 아니다**라는 조건이다. 그리고 이 비용으로 잰 경로 비용은 원래 비용에서 상수 $h(s) - h(\text{목표})$만큼 차이 날 뿐이라 최소를 주는 경로가 바뀌지 않는다.

즉 ==일관된 휴리스틱 위의 A\*는 재조정된 비용 위의 다익스트라다.== 다익스트라가 "가중치가 음수가 아니다"를 요구했던 자리에 A\*는 "일관성"을 요구한다. 같은 요구다. §2.2의 등가성이 $h=0$이라는 특수한 경우를 넘어 일반적으로 성립하는 이유가 여기에 있다.
:::

### 2.5 허용적인데 일관되지 않으면

두 조건이 다르다는 것을 그림이 아니라 숫자로 보인다. 정점 4개짜리 그래프다.

```text nolines
   S --1--> A --1--> B --5--> G
   S --4----------> B                <- 지름길처럼 보이는 비싼 간선

   진짜 남은 비용  h*(S)=7  h*(A)=6  h*(B)=5  h*(G)=0
   쓸 휴리스틱     h(S)=0   h(A)=6   h(B)=0   h(G)=0
```

$h$는 어느 정점에서도 $h^*$를 넘지 않는다. **허용적이다.** 그런데 간선 $A \to B$에서 $h(A) = 6$이고 $w + h(B) = 1 + 0 = 1$이므로 $6 \le 1$이 거짓이다. **일관되지 않다.** $A$에서만 추정이 정확하고 나머지에서는 0으로 뭉갠 셈이라, $A$를 지나는 순간 추정치가 절벽처럼 떨어진다.

이 $h$로 A\*를 돌리면 $B$가 $g = 4$로 먼저 닫히고, 나중에 $A$를 꺼냈을 때 $g = 2$짜리 경로가 나타난다. **이미 닫은 $B$를 다시 열어야 한다.** 손으로 확인한다.

### 2.6 맨해튼 거리는 왜 안전한가

4방향 격자에서 한 칸 이동의 비용이 1일 때 $h(r, c) = |r - g_r| + |c - g_c|$를 쓴다.

- **허용적이다.** 한 번 이동하면 행 차이나 열 차이 중 하나가 1 줄어든다. 둘이 동시에 줄지는 않는다. 그러므로 목표에 닿으려면 최소 $|\Delta r| + |\Delta c|$번 이동해야 하고 각 이동의 비용이 1 이상이다. 벽이 있으면 실제 비용은 더 커지므로 부등호가 더 벌어질 뿐이다.
- **일관하다.** 인접한 두 칸의 맨해튼 값 차이는 항상 정확히 1이다. 따라서 $h(u) - h(v) \le 1 = w(u,v)$다.

::: danger
**대각선 이동을 비용 1로 허용하는 순간 맨해튼은 허용적이지 않다.** 목표의 대각선 이웃 칸은 실제로 한 번에 갈 수 있으므로 $h^* = 1$인데 맨해튼은 2를 준다. 과대평가이고, §2.3의 논증이 무너져 **최적이 아닌 경로를 답으로 내놓을 수 있다.** 이때는 체비셰프 거리 $\max(|\Delta r|, |\Delta c|)$나, 대각선 비용이 $\sqrt 2$면 옥타일 거리를 쓴다.

칸마다 통행 비용이 다른 지형에서도 조건은 하나다 — **최소 통행 비용이 1 이상**이어야 맨해튼이 허용적이다. 비용이 0.5인 칸이 하나라도 있으면 깨진다. 이때는 맨해튼에 최소 비용을 곱한 값을 쓴다.
:::

## 3. 손으로 따라가기

::: trace
§2.5의 그래프와 휴리스틱이다. 간선은 `S→A 1`, `S→B 4`, `A→B 1`, `B→G 5`. 휴리스틱은 `h = [S:0, A:6, B:0, G:0]`.

규칙은 셋이다. **꺼낼 때는 $f$가 가장 작은 것**, 꺼낸 정점은 **닫는다**, 닫힌 정점의 $g$를 줄이는 경로가 나오면 **다시 연다**.

| 스텝 | 꺼낸 정점 | g | f | 이번에 갱신된 것 | 열린 목록 (f 순) |
|---|---|---|---|---|---|
| 1 | S | 0 | 0 | A: g=1 f=7, B: g=4 f=4 | B(4) A(7) |
| 2 | B | 4 | 4 | G: g=9 f=9 | A(7) G(9) |
| 3 | | | | | |
| 4 | | | | | |
| 5 | | | | | |

세 가지를 확인하라.

- [ ] 스텝 3에서 $A$를 꺼낼 때 $B$의 $g$는 얼마가 되는가. $B$는 이미 닫혀 있는데 그 값을 버릴 수 있는가
- [ ] $G$의 $g$는 몇 번 바뀌는가. 최종 답은 얼마인가
- [ ] 같은 그래프에서 $h$를 $h^*$ = `[7, 6, 5, 0]`으로 바꾸면 각 스텝의 $f$는 어떻게 되는가. 재열기가 일어나는가
:::

::: answer
| 스텝 | 꺼낸 정점 | g | f | 이번에 갱신된 것 | 열린 목록 (f 순) |
|---|---|---|---|---|---|
| 1 | S | 0 | 0 | A: g=1 f=7, B: g=4 f=4 | B(4) A(7) |
| 2 | B | 4 | 4 | G: g=9 f=9 | A(7) G(9) |
| 3 | A | 1 | 7 | **B 재열기** g=4 → 2, f=2 | B(2) G(9) |
| 4 | B | 2 | 2 | G: g=9 → 7, f=7 | G(7) |
| 5 | G | 7 | 7 | — | — |

첫 번째. $A$의 $g$가 1이므로 $A \to B$로 가면 $g(B) = 2$이고, 닫을 때의 4보다 작다. **버릴 수 없다.** 버리면 $B$를 거쳐 가는 모든 경로가 2만큼 비싼 채로 굳는다. 그래서 $B$를 닫힌 목록에서 빼고 $f = 2$로 다시 넣는다. $B$는 결국 **두 번 확장된다.**

두 번째. $G$의 $g$는 9로 한 번 정해진 뒤 7로 한 번 고쳐진다. 최종 답은 7이고 이것이 진짜 최단이다. ==허용적이기만 하면 답은 맞는다. 다시 여는 수고를 치를 뿐이다.== 두 조건이 보장하는 것이 서로 다르다는 말의 뜻이 이것이다.

세 번째. $h = h^*$는 일관하다. 그러면 다섯 스텝이 넷으로 줄고 $f$가 전부 7이 된다.

| 스텝 | 꺼낸 정점 | g | f |
|---|---|---|---|
| 1 | S | 0 | 7 |
| 2 | A | 1 | 7 |
| 3 | B | 2 | 7 |
| 4 | G | 7 | 7 |

$f$가 한 번도 줄지 않는다(여기서는 아예 안 변한다). §2.4가 증명한 그대로다. $B$는 스텝 2에서 $g$가 4에서 2로 좋아지지만 그때 $B$는 **아직 열려 있어서** 값만 고치면 된다. 닫힌 것을 다시 여는 것과는 다른 사건이다.
:::

## 4. 구현

### 4.1 재열기를 세어 확인한다

§3을 코드로 옮기고, 허용성과 일관성을 **선언하지 않고 검사한다.**

::: dual
```python title="허용적이지만 일관되지 않은 휴리스틱 — 재열기 관찰"
import heapq

INF = 10 ** 9
NAME = ["S", "A", "B", "G"]
EDGES = [(0, 1, 1), (0, 2, 4), (1, 2, 1), (2, 3, 5)]
N = 4
START, GOAL = 0, 3
HSTAR = [7, 6, 5, 0]                 # 각 정점에서 G 까지의 진짜 최소 비용
H_BAD = [0, 6, 0, 0]                 # 과대평가는 없다. 삼각부등식은 A→B 에서 깨진다
H_GOOD = [7, 6, 5, 0]

ADJ = [[] for _ in range(N)]
for u, v, w in EDGES:
    ADJ[u].append((v, w))


def check(h):
    """admissible 과 consistent 를 실제로 검사한다. 선언이 아니라 계산이다."""
    adm = all(h[v] <= HSTAR[v] for v in range(N))
    bad_edge = ""
    for u, v, w in EDGES:
        if h[u] > w + h[v]:
            bad_edge = NAME[u] + "→" + NAME[v]
            break
    con = (bad_edge == "") and h[GOAL] == 0
    return adm, con, bad_edge


def astar(h):
    """닫힌 목록을 두고, 더 짧은 경로가 나중에 나타나면 닫힌 정점을 다시 연다."""
    g = [INF] * N
    g[START] = 0
    closed = [False] * N
    pq = [(h[START], 0, START)]
    expanded = 0
    reopened = 0
    while pq:
        f, gu, u = heapq.heappop(pq)
        if gu > g[u]:
            continue                 # 낡은 항목
        expanded += 1
        print("      꺼냄 " + NAME[u] + "  g=" + str(gu) + "  f=" + str(f))
        if u == GOAL:
            break
        closed[u] = True
        for v, w in ADJ[u]:
            ng = gu + w
            if ng < g[v]:
                if closed[v]:
                    closed[v] = False
                    reopened += 1
                    print("        " + NAME[v] + " 재열기: 닫을 때 g=" + str(g[v])
                          + " 였는데 g=" + str(ng) + " 가 나왔다")
                g[v] = ng
                heapq.heappush(pq, (ng + h[v], ng, v))
    return g[GOAL], expanded, reopened

    print(title + "  h = [" + ", ".join(str(x) for x in h) + "]")
    print("    admissible " + str(adm) + " / consistent " + str(con)
          + ("" if con else "  (깨지는 간선 " + bad_edge + ")"))
    cost, expanded, reopened = astar(h)

          + "회 / 재열기 " + str(reopened) + "회")
```

```cpp title="허용적이지만 일관되지 않은 휴리스틱 — 재열기 관찰"
#include <queue>
#include <string>
#include <tuple>
#include <vector>
using namespace std;

const int INF = 1000000000;
const string NAME[4] = {"S", "A", "B", "G"};
vector<tuple<int, int, int>> EDGES = {{0, 1, 1}, {0, 2, 4}, {1, 2, 1}, {2, 3, 5}};
const int N = 4;
const int START = 0, GOAL = 3;
vector<int> HSTAR = {7, 6, 5, 0};        // 각 정점에서 G 까지의 진짜 최소 비용
vector<int> H_BAD = {0, 6, 0, 0};        // 과대평가는 없다. 삼각부등식은 A→B 에서 깨진다
vector<int> H_GOOD = {7, 6, 5, 0};

vector<vector<pair<int, int>>> ADJ(N);

// admissible 과 consistent 를 실제로 검사한다. 선언이 아니라 계산이다.
void check(const vector<int>& h, bool& adm, bool& con, string& bad_edge) {
    adm = true;
    for (int v = 0; v < N; v++)
        if (h[v] > HSTAR[v]) adm = false;
    bad_edge = "";
    for (auto [u, v, w] : EDGES) {
        if (h[u] > w + h[v]) {
            bad_edge = NAME[u] + "→" + NAME[v];
            break;
        }
    }
    con = (bad_edge == "") && h[GOAL] == 0;
}

// 닫힌 목록을 두고, 더 짧은 경로가 나중에 나타나면 닫힌 정점을 다시 연다.
int astar(const vector<int>& h, int& expanded, int& reopened) {
    vector<int> g(N, INF);
    g[START] = 0;
    vector<bool> closed(N, false);
    priority_queue<tuple<int, int, int>, vector<tuple<int, int, int>>, greater<>> pq;
    pq.push({h[START], 0, START});
    expanded = 0;
    reopened = 0;
    while (!pq.empty()) {
        auto [f, gu, u] = pq.top();
        pq.pop();
        if (gu > g[u]) continue;         // 낡은 항목
        expanded++;
        cout << "      꺼냄 " << NAME[u] << "  g=" << gu << "  f=" << f << "\n";
        if (u == GOAL) break;
        closed[u] = true;
        for (auto [v, w] : ADJ[u]) {
            int ng = gu + w;
            if (ng < g[v]) {
                if (closed[v]) {
                    closed[v] = false;
                    reopened++;
                    cout << "        " << NAME[v] << " 재열기: 닫을 때 g=" << g[v]
                         << " 였는데 g=" << ng << " 가 나왔다\n";
                }
                g[v] = ng;
                pq.push({ng + h[v], ng, v});
            }
        }
    }
    return g[GOAL];
}

    bool adm, con;
    string bad_edge;
    check(h, adm, con, bad_edge);
    cout << title << "  h = [";
    for (int i = 0; i < N; i++) cout << (i ? ", " : "") << h[i];
    cout << "]\n";
    cout << "    admissible " << (adm ? "True" : "False") << " / consistent "
         << (con ? "True" : "False")
         << (con ? "" : "  (깨지는 간선 " + bad_edge + ")") << "\n";
    int expanded = 0, reopened = 0;
    int cost = astar(h, expanded, reopened);
    cout << "    최단 비용 " << cost << " / 확장 " << expanded
         << "회 / 재열기 " << reopened << "회\n";
}

int main() {

    cout << "간선  S→A 1, S→B 4, A→B 1, B→G 5   (진짜 최단 S→A→B→G = 7)\n";

    report("[2] 일관된 h", H_GOOD);

}
```

### 4.2 격자 A\*와 다익스트라를 나란히 돌린다

같은 격자에서 다익스트라, $h=0$인 A\*, 맨해튼 A\*를 각각 돌리고 **확장 순서와 비용을 대조한다.**

```python title="격자 A* — h 를 갈아 끼우고 확장 수를 센다"
import heapq

R, C = 21, 21
SR, SC = 10, 0
GR, GC = 10, 20
DR = (-1, 1, 0, 0)
DC = (0, 0, -1, 1)


def build_wall():
    wall = [[False] * C for _ in range(R)]
    for r in range(0, 15):
        wall[r][10] = True          # 가운데를 세로로 막는다. 아래로 돌아가야 한다
    return wall


WALL = build_wall()


def h_zero(r, c):
    return 0


def h_manhattan(r, c):
    return abs(r - GR) + abs(c - GC)


def astar(h):
    """열린 목록에서 f = g + h 가 가장 작은 칸을 꺼낸다. h 가 0 이면 f = g 다."""
    INF = 10 ** 9
    g = [[INF] * C for _ in range(R)]
    g[SR][SC] = 0
    pq = [(h(SR, SC), 0, SR, SC)]
    expanded = 0
    order = []
    while pq:
        f, gu, r, c = heapq.heappop(pq)
        if gu > g[r][c]:
            continue                 # 낡은 항목. 이미 더 좋은 값으로 처리했다
        expanded += 1
        order.append(r * C + c)
        if (r, c) == (GR, GC):
            return g[GR][GC], expanded, order
        for k in range(4):
            nr, nc = r + DR[k], c + DC[k]
            if not (0 <= nr < R and 0 <= nc < C):
                continue
            if WALL[nr][nc]:
                continue
            ng = gu + 1
            if ng < g[nr][nc]:
                g[nr][nc] = ng
                heapq.heappush(pq, (ng + h(nr, nc), ng, nr, nc))
    return INF, expanded, order


def dijkstra():
    """A* 와 독립으로 짠 다익스트라. 우선순위가 g 하나뿐이다."""
    INF = 10 ** 9
    g = [[INF] * C for _ in range(R)]
    g[SR][SC] = 0
    pq = [(0, SR, SC)]
    expanded = 0
    order = []
    while pq:
        gu, r, c = heapq.heappop(pq)
        if gu > g[r][c]:
            continue
        expanded += 1
        order.append(r * C + c)
        if (r, c) == (GR, GC):
            return g[GR][GC], expanded, order
        for k in range(4):
            nr, nc = r + DR[k], c + DC[k]
            if not (0 <= nr < R and 0 <= nc < C):
                continue
            if WALL[nr][nc]:
                continue
            ng = gu + 1
            if ng < g[nr][nc]:
                g[nr][nc] = ng
                heapq.heappush(pq, (ng, nr, nc))
    return INF, expanded, order


cd, ed, od = dijkstra()
c0, e0, o0 = astar(h_zero)
cm, em, om = astar(h_manhattan)

print("격자 21x21, 시작 (10,0), 목표 (10,20), 가운데 세로벽")
```

```cpp title="격자 A* — h 를 갈아 끼우고 확장 수를 센다"
#include <cmath>
#include <iostream>
#include <queue>
#include <string>
#include <tuple>
#include <vector>
using namespace std;

const int R = 21, C = 21;
const int SR = 10, SC = 0;
const int GR = 10, GC = 20;
const int DR[4] = {-1, 1, 0, 0};
const int DC[4] = {0, 0, -1, 1};

vector<vector<bool>> build_wall() {
    vector<vector<bool>> wall(R, vector<bool>(C, false));
    for (int r = 0; r < 15; r++)
        wall[r][10] = true;              // 가운데를 세로로 막는다. 아래로 돌아가야 한다
    return wall;
}

vector<vector<bool>> WALL = build_wall();

int h_zero(int r, int c) { return 0; }

int h_manhattan(int r, int c) { return abs(r - GR) + abs(c - GC); }

// 열린 목록에서 f = g + h 가 가장 작은 칸을 꺼낸다. h 가 0 이면 f = g 다.
int astar(int (*h)(int, int), int& expanded, vector<int>& order) {
    const int INF = 1000000000;
    vector<vector<int>> g(R, vector<int>(C, INF));
    g[SR][SC] = 0;
    priority_queue<tuple<int, int, int, int>, vector<tuple<int, int, int, int>>, greater<>> pq;
    pq.push({h(SR, SC), 0, SR, SC});
    expanded = 0;
    order.clear();
    while (!pq.empty()) {
        auto [f, gu, r, c] = pq.top();
        pq.pop();
        if (gu > g[r][c]) continue;      // 낡은 항목. 이미 더 좋은 값으로 처리했다
        expanded++;
        order.push_back(r * C + c);
        if (r == GR && c == GC) return g[GR][GC];
        for (int k = 0; k < 4; k++) {
            int nr = r + DR[k], nc = c + DC[k];
            if (!(0 <= nr && nr < R && 0 <= nc && nc < C)) continue;
            if (WALL[nr][nc]) continue;
            int ng = gu + 1;
            if (ng < g[nr][nc]) {
                g[nr][nc] = ng;
                pq.push({ng + h(nr, nc), ng, nr, nc});
            }
        }
    }
    return INF;
}

// A* 와 독립으로 짠 다익스트라. 우선순위가 g 하나뿐이다.
int dijkstra(int& expanded, vector<int>& order) {
    const int INF = 1000000000;
    vector<vector<int>> g(R, vector<int>(C, INF));
    g[SR][SC] = 0;
    priority_queue<tuple<int, int, int>, vector<tuple<int, int, int>>, greater<>> pq;
    pq.push({0, SR, SC});
    expanded = 0;
    order.clear();
    while (!pq.empty()) {
        auto [gu, r, c] = pq.top();
        pq.pop();
        if (gu > g[r][c]) continue;
        expanded++;
        order.push_back(r * C + c);
        if (r == GR && c == GC) return g[GR][GC];
        for (int k = 0; k < 4; k++) {
            int nr = r + DR[k], nc = c + DC[k];
            if (!(0 <= nr && nr < R && 0 <= nc && nc < C)) continue;
            if (WALL[nr][nc]) continue;
            int ng = gu + 1;
            if (ng < g[nr][nc]) {
                g[nr][nc] = ng;
                pq.push({ng, nr, nc});
            }
        }
    }
    return INF;
}

int main() {
    int ed = 0, e0 = 0, em = 0;
    vector<int> od, o0, om;
    int cd = dijkstra(ed, od);
    int c0 = astar(h_zero, e0, o0);
    int cm = astar(h_manhattan, em, om);

    cout << "격자 21x21, 시작 (10,0), 목표 (10,20), 가운데 세로벽\n";
    cout << "다익스트라      비용 " << cd << " / 확장 " << ed << "\n";
    cout << "A* (h=0)       비용 " << c0 << " / 확장 " << e0 << "\n";
    cout << "A* (h=맨해튼)   비용 " << cm << " / 확장 " << em << "\n";
    cout << "h=0 인 A* 의 확장 순서가 다익스트라와 같은가: " << (o0 == od ? "True" : "False") << "\n";
    cout << "맨해튼 A* 가 같은 최단 비용을 내는가: " << (cm == cd ? "True" : "False") << "\n";
    return 0;
}
```

$h = 0$인 A\*는 다익스트라와 **확장한 칸의 순서까지 완전히 같다.** §2.2가 주장한 등가성이 코드에서 그대로 확인된다. 격자만이 아니다 — 무작위 양수 가중 그래프 500개에서도 $h = 0$인 A\*의 확장 순서는 다익스트라와 **500/500 일치**하고, 허용적인 $h$를 무엇으로 주든 답은 전부 같다(`tools/bench/v45_order_agreement.py`). 맨해튼으로 바꾸면 같은 비용 30을 370칸이 아니라 171칸으로 찾는다.

여기 A\*에는 `closed` 배열이 없다. **맨해튼이 일관하므로 재열기가 원리상 일어나지 않고**, 낡은 힙 항목은 `gu > g[r][c]` 한 줄로 걸러진다. §4.1처럼 일관성이 보장되지 않는 상황에서만 닫힌 목록이 필요하다.

**복잡도:** 시간 $O(E \log V)$ — 격자에서는 정점이 $RC$개, 각 칸의 차수가 4로 묶여 $E \le 4RC$이므로 $O(RC \log(RC))$다. **A\*의 이득은 이 식의 $E$와 $V$를 줄이는 것이 아니라 목표를 찾기 전에 건드리는 정점의 수를 줄이는 것이라 복잡도 표기에는 안 나타난다.** 최악은 여전히 전부 확장이다. 공간 $O(RC)$ — `g` 배열과 힙.

| 힙 항목 비교 | 튜플이 사전식으로 비교된다. `(f, g, r, c)`면 `f` → `g` 순 | `tuple`도 사전식 비교. 동점 처리 규칙이 같아야 확장 순서가 일치한다 |
| $h$ 갈아 끼우기 | 함수를 인자로 그대로 넘긴다 | 함수 포인터 `int (*h)(int,int)` 또는 템플릿. `std::function`은 호출마다 간접 분기 비용이 붙는다 |
| 실수 휴리스틱 | 유클리드를 쓰면 부동소수 비교가 된다 | 같은 문제. 정수 격자에서는 정수 휴리스틱을 쓰는 편이 안전하다([X-7](#/x-7)) |

::: pitfall
- **목표를 힙에 넣는 순간 종료한다.** 종료는 목표를 **꺼낼 때** 해야 한다. 넣는 시점의 $g$는 아직 최적이 아닐 수 있다. §3의 스텝 2에서 $G$가 $g = 9$로 들어갔다가 7로 고쳐진 것이 정확히 그 사례다.
- **일관성 없는 $h$를 쓰면서 닫힌 정점을 무조건 건너뛴다.** 답이 조용히 나빠진다. 일관성을 확신할 수 없으면 재열기를 허용하거나 $h$를 고쳐라.
- **대각선 이동을 허용하면서 맨해튼을 그대로 쓴다.** 허용성이 깨지고 최적이 아닌 경로가 나온다.
- **$h$에 가중치를 곱해 놓고 최적을 기대한다.** $h$를 1.5배 하면 빨라지지만 최적성은 사라진다. 그것을 의도적으로 하는 것이 [V-6](#/v-6)이다.
- **모든 정점에 대한 거리장이 필요한데 A\*를 쓴다.** A\*는 목표를 꺼내는 즉시 멈추므로 다른 칸의 $g$는 확정값이 아니다. 거리장이 필요하면 [V-1](#/v-1)을 끝까지 돌린다.
:::

## 5. 어디에 쓰이는가

**로봇의 전역 경로계획이 코스트맵 위의 A\*다.** 점유 격자 지도에 장애물로부터의 거리에 따라 비용을 부풀린(인플레이션) 코스트맵을 깔고, 그 위에서 시작에서 목표까지의 경로를 뽑는다. 인플레이션 비용이 기본 통행 비용에 **더해지는** 형태라 최소 통행 비용이 1 이상으로 유지되고, 그래서 맨해튼·유클리드 휴리스틱의 허용성이 유지된다. §2.6의 조건이 실무 설계 제약으로 그대로 나타나는 지점이다. 뽑힌 전역 경로를 실제 속도 명령으로 바꾸는 것은 별도의 지역 계획기가 맡는다([V-12](#/v-12)).

**게임의 유닛 이동이 타일 격자나 내비메시 위의 A\*다.** 여기서 확장 칸 수는 곧 프레임 예산이다. 한 프레임이 16 ms인데 유닛 200기가 각자 경로를 요청하면 요청당 예산이 수십 마이크로초다. 그래서 게임 쪽에서는 경로 요청을 여러 프레임에 나눠 처리하거나, 최적성을 조금 포기하고 확장 수를 줄이는 [V-6](#/v-6)의 기법을 먼저 꺼낸다.

**도로망 내비게이션에서 허용성은 "안전한 하한"이라는 실무 용어가 된다.** 소요 시간을 최소화하려면 $h$도 시간 단위여야 하고, 두 지점 사이의 직선거리를 그 지역 **최고** 제한속도로 나눈 값을 쓴다. 최고 속도로 나누는 이유가 곧 허용성이다 — 어떤 경로도 그보다 빨리 갈 수 없으므로 과대평가가 아니다. 평균 속도로 나누면 더 빨라지지만 최적 경로를 놓칠 수 있다. **"어느 쪽으로 틀려도 되는가"를 아는 것이 이 조건의 값어치다.**

## 6. 이 유형을 알아보는 법

::: classify
- 신호어: "출발지에서 목적지까지" 한 쌍만 묻는다, "가장 빨리 도착", "최소 비용 경로를 출력" + 목표의 좌표나 위치를 알 수 있다. 요구사항 문장이라면 "경로 요청이 초당 수십 번 들어온다"
- 제약조건: 가중치가 음수가 아니고 목표가 하나로 정해진다. 상태가 격자·좌표처럼 **거리를 잴 수 있는** 공간에 놓여 있어야 $h$를 만들 수 있다. 그런 구조가 없으면 $h$를 만들 수 없고 A\*의 이득도 없다
- 혼동 주의: 모든 정점까지의 거리장이 필요하면 → [V-1](#/v-1). 목표가 여럿이거나 시작이 여럿이면 휴리스틱이 약해져 이득이 준다 → [IV-4](#/iv-4). 가중치가 전부 1이면 → [IV-3](#/iv-3). 최적성을 포기해도 되면 → [V-6](#/v-6). 지도가 실행 중에 바뀌면 → [V-7](#/v-7)
- 반례 함정: 대각선 이동을 허용하면서 맨해튼을 쓰는 것. 통행 비용이 1 미만인 칸이 섞이는 것. 그리고 목표를 힙에 넣을 때 종료하는 것 — 셋 다 답이 조용히 나빠지고 예외는 나지 않는다
:::

::: interview
**"A\*와 다익스트라의 차이가 무엇입니까."**
"우선순위가 다릅니다. 다익스트라는 $g$, A\*는 $g + h$입니다. 그래서 **$h = 0$인 A\*가 곧 다익스트라입니다** — 별개의 알고리즘이 아니라 같은 알고리즘의 특수한 경우입니다." 여기에 "다익스트라는 목표를 인자로 받지도 않기 때문에 목표 쪽을 우대할 수가 없다"를 덧붙이면 왜 그 차이가 생기는지까지 말한 것이 된다.

**"admissible과 consistent는 어떻게 다릅니까."**
"허용성은 $h \le h^*$, 과대평가하지 않는다는 조건이고 **답의 최적성**을 보장합니다. 일관성은 $h(u) \le w(u,v) + h(v)$, 삼각부등식이고 **닫은 노드를 다시 열지 않음**을 보장합니다. 일관하면 허용적이지만 반대는 아닙니다." 반례를 그 자리에서 그릴 수 있으면 확실해진다 — §2.5의 정점 4개짜리 그래프면 충분하다. "실무 격자에서 쓰는 맨해튼·유클리드는 둘 다 만족하므로 재열기를 신경 쓸 필요가 없습니다"까지 가면 실제로 써 본 답이 된다.
:::

## 연습

::: quiz
A\*는 코딩테스트에 거의 나오지 않는다. 나오는 곳은 설계 질문이다. 셋 다 **무엇을 상태로 두고 $h$를 어떻게 만들 것인가**가 본론이다.

**1. 창고 로봇의 경로 요청**
- 상황: $200 \times 200$ 격자 창고. 로봇 한 대가 현재 위치에서 지정된 선반까지 갈 경로를 요청한다. 요청은 초당 30건이고 응답은 10 ms 안에 와야 한다. 바닥 종류에 따라 통행 비용이 1, 2, 3으로 다르다.
- 무엇을 상태로 두는가: 칸 `(r, c)`. 비용은 칸에 들어가는 값으로 잡는다.
- 왜 이 알고리즘인가 / 무엇을 포기하는가: 목표가 하나이고 좌표가 있으므로 $h$를 만들 수 있다. 최소 통행 비용이 1이므로 맨해튼을 그대로 써도 허용적이다. 만약 비용이 0.5인 바닥이 생기면 무엇을 고쳐야 하는지 답할 수 있어야 한다.

**2. 게임 유닛 200기의 동시 이동 명령**
- 상황: 플레이어가 유닛 200기를 선택해 한 지점으로 보낸다. 프레임 예산은 16 ms이고 경로 계산에 쓸 수 있는 것은 그중 4 ms다.
- 무엇을 상태로 두는가: 타일 좌표. 다만 **목표가 하나이고 시작이 200개**라는 점이 뒤집혀 있다.
- 왜 이 알고리즘인가 / 무엇을 포기하는가: 시작이 여럿이고 목표가 하나면 방향을 뒤집어 목표에서 한 번만 [V-1](#/v-1)을 돌려 거리장을 만드는 편이 200번의 A\*보다 싸다. **A\*가 항상 이기지 않는다** — 어떤 조건에서 뒤집히는지가 이 문제의 답이다.

**3. 대륙 규모 도로망의 경로 안내**
- 상황: 정점 2천만 개의 도로망. 목적은 소요 시간 최소화이고 응답은 100 ms 안이다.
- 무엇을 상태로 두는가: 교차로 정점. 간선 비용은 거리가 아니라 **시간**이다.
- 왜 이 알고리즘인가 / 무엇을 포기하는가: $h$의 단위를 비용과 맞춰야 하므로 직선거리를 최고 제한속도로 나눈다. 이 $h$가 왜 허용적인지, 그리고 왜 매우 약한지(직선거리는 실제 도로 시간을 크게 밑돈다) 설명할 수 있어야 한다. 약한 휴리스틱을 보강하는 방향이 [V-6](#/v-6)의 주제다.
:::

## 요약

- A\*는 다익스트라의 우선순위를 $g$에서 $f = g + h$로 바꾼 것이다. **$h = 0$이면 $f = g$이고 그것이 곧 다익스트라다.** 두 알고리즘이 아니라 하나의 알고리즘에 $h$를 무엇으로 주느냐다.
- **admissible($h \le h^*$)** 은 답의 최적성을 보장한다. 목표를 꺼낼 때 최적 경로 위의 열린 정점과 $f$를 비교하면 나온다.
- **consistent($h(u) \le w(u,v) + h(v)$)** 는 닫은 정점을 다시 열지 않음을 보장한다. 간선을 따라 $f$가 줄지 않기 때문이다.
- **둘은 다르다.** 정점 4개짜리 그래프에서 허용적이지만 일관되지 않은 $h$는 답 7을 맞히면서 $B$를 두 번 확장한다(확장 5회 대 4회).
- 일관성은 재조정된 간선 비용 $w + h(v) - h(u)$가 음수가 아니라는 조건과 같다. **일관된 A\*는 재조정된 비용 위의 다익스트라다.**
- 4방향 격자에서 맨해튼은 허용적이고 일관하다. **대각선 이동을 허용하거나 통행 비용이 1 미만이면 깨진다.**
- 이득은 실측으로 150배까지 나지만 0일 수도 있다. **$h$의 정확도가 아니라 $f$ 값이 칸마다 갈리는 정도가 이득을 만든다.**
