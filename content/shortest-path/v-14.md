# V-14 계보 총정리

::: lead
BFS와 CBS는 다른 알고리즘인가, 아니면 같은 알고리즘의 다른 설정인가.
:::

## 1. 문제

Part V를 다 읽고 나면 이름이 열네 개 남는다. 다익스트라, 벨만-포드, 플로이드-워셜, A\*, Weighted A\*, JPS, Theta\*, LPA\*, D\* Lite, 시공간 A\*, CBS, 헝가리안, DWA, RRT.

이 상태로는 못 쓴다. **이름을 아는 것과 문제 앞에서 하나를 고르는 것은 다른 능력이다**([I-1](#/i-1)). 열네 개를 각각 기억하면 고를 때 열네 번 비교해야 하고, 열네 번 비교하는 사람은 5분 안에 결정하지 못한다.

그리고 열네 개를 따로 기억하는 것은 사실과도 다르다. 이 챕터가 증명할 명제는 이것이다.

> **이 계보의 알고리즘들은 하나의 탐색 뼈대에서 "다음에 무엇을 꺼낼 것인가"만 바꾼 것이다.**

이 명제가 참이면 기억할 것은 열네 개가 아니라 **뼈대 하나와 바뀐 지점 여섯 개**다. 문제 앞에서 물어야 할 것도 "어떤 알고리즘인가"가 아니라 **"내 상황이 뼈대의 어느 가정을 깨뜨리는가"**가 된다.

## 2. 지도 한 장

### 2.1 척추

```text nolines
   ┌──────────────────┐
   │ BFS              │   IV-3   큐 하나. 모든 간선 비용이 1
   └─────────┬────────┘
             │               큐 -> 우선순위 큐
             ▼
   ┌──────────────────┐
   │ Dijkstra         │ ──▶ Bellman-Ford / Floyd-Warshall  V-2, V-3   음수 간선, 모든 쌍
   └─────────┬────────┘
             │               우선순위 g -> g + h
             ▼
   ┌──────────────────┐
   │ A*               │ ──▶ Weighted A* / JPS / Theta*     V-6   h -> eps*h, 대칭 제거, 격자 이탈
   └─────────┬────────┘
             │               전체 재계산 -> 증분 갱신
             ▼
   ┌──────────────────┐
   │ LPA* / D* Lite   │   V-7    바뀐 구간만 다시 푼다
   └─────────┬────────┘
             │               상태 s -> (s, t)
             ▼
   ┌──────────────────┐
   │ Space-Time A*    │   V-8    시간 축을 상태에 넣는다
   └─────────┬────────┘
             │               에이전트 1 -> N. 충돌을 제약으로 되먹인다
             ▼
   ┌──────────────────┐
   │ CBS              │   V-9    제약 트리의 각 노드가 다시 V-8 을 부른다
   └──────────────────┘
```

화살표마다 **정확히 한 가지**가 바뀐다.

| 구간 | 바뀐 것 | 얻은 것 | 잃은 것 |
|---|---|---|---|
| [IV-3](#/iv-3) → [V-1](#/v-1) | 큐 → 우선순위 큐 | 간선 비용이 달라도 최단 | $O(V+E)$ → $O(E \log V)$ |
| [V-1](#/v-1) → [V-2](#/v-2) | 순서 포기, V-1회 반복 | 음수 간선과 음수 사이클 검출 | $O(VE)$ |
| [V-1](#/v-1) → [V-3](#/v-3) | 경유점 k를 바깥 루프로 | 모든 쌍 동시에 | $O(V^3)$, $O(V^2)$ 메모리 |
| [V-1](#/v-1) → [V-5](#/v-5) | 우선순위 `g` → `g + h` | 같은 답을 더 적게 펼쳐서 | 휴리스틱을 설계해야 한다 |
| [V-5](#/v-5) → [V-6](#/v-6) | `h` → `ε·h` | 확장 수 급감 | **최적성**(답이 최대 ε배) |
| [V-5](#/v-5) → [V-7](#/v-7) | 전체 재계산 → 증분 갱신 | 지도가 바뀌어도 싸게 | 상태 두 개(`g`, `rhs`) 관리 |
| [V-5](#/v-5) → [V-8](#/v-8) | 상태 `s` → `(s, t)` | 다른 에이전트의 미래를 피한다 | 상태 공간 × 시간 지평 |
| [V-8](#/v-8) → [V-9](#/v-9) | 에이전트 1 → N + 제약 트리 | 다중 에이전트 최적 | 최악에 지수. 트리 하나가 통째로 커진다 |

[V-4 DP와 최단경로는 같은 것이다](#/v-4)가 이 표 전체의 밑바닥이다. 세 알고리즘은 서로 다른 발명이 아니라 **벨만 방정식이라는 하나의 점화식을 어떤 순서로 푸느냐**의 차이다. 다익스트라는 확정된 거리가 작은 것부터, 벨만-포드는 순서를 포기하고 반복으로, 플로이드-워셜은 경유점을 바깥 루프로 놓는다.

### 2.3 같은 격자, 다른 우선순위

네 패널이 **같은 격자·같은 시작·같은 목표**를 쓴다. 스텝을 밀면 넷이 동시에 자란다. 보아야 할 것은 확장된 칸의 개수가 아니라 **자라는 모양**이다.

- **BFS**는 시작점을 중심으로 동심원이다. 큐가 거리 순으로 정렬되어 있기 때문이다.
- **DFS**는 실뭉치다. 최단을 보장하지 않는다는 것이 화면에 그대로 보인다.
- **다익스트라**는 등가 비용 등고선이다. 지형 비용이 켜지면 동심원이 비싼 지형 쪽으로 찌그러진다.
- **A\***는 목표를 향한 쐐기다. 답은 다익스트라와 같고 펼친 칸만 줄어든다.

휴리스틱을 `zero`로 두면 A\* 패널이 다익스트라 패널과 같아진다. ==다익스트라는 `h = 0`인 A\*다.== 위젯에서 직접 확인하라 — 두 패널의 확장 칸 수가 같은 숫자가 된다.

## 3. 손으로 따라가기

::: trace
정점 다섯 개짜리 그래프다.

```text nolines
   S --2--> A --3--> C --4--> G
   S --5--> B --2--> G
```

목표 G까지의 휴리스틱은 `h(S)=6, h(A)=5, h(B)=2, h(C)=4, h(G)=0`이다. 실제 거리(S에서 7, A에서 7, B에서 2, C에서 4)를 넘지 않으므로 admissible이고, 모든 간선에서 `h(u) ≤ w(u,v) + h(v)`이므로 consistent다.

두 탐색을 나란히 돌린다. **꺼내는 우선순위만 다르다** — 다익스트라는 `g`, A\*는 `f = g + h`. 동점이면 알파벳 순으로 꺼낸다.

| 스텝 | 다익스트라가 꺼낸 것 (g) | A\*가 꺼낸 것 (f = g + h) |
|---|---|---|
| 1 | S (0) | S (0 + 6 = 6) |
| 2 | A (2) | A (2 + 5 = 7) |
| 3 | | |
| 4 | | |
| 5 | | |

**둘 중 하나는 5스텝을 다 쓰지 않는다.** 어느 쪽이 몇 스텝에 끝나고, **끝까지 한 번도 안 꺼내진 정점은 무엇인가.**
:::

::: answer
| 스텝 | 다익스트라가 꺼낸 것 (g) | A\*가 꺼낸 것 (f = g + h) |
|---|---|---|
| 1 | S (0) | S (0 + 6 = 6) |
| 2 | A (2) | A (2 + 5 = 7) |
| 3 | B (5) | B (5 + 2 = 7) |
| 4 | C (5) | **G (7 + 0 = 7)** — 종료 |
| 5 | G (7) | — |

**다익스트라 5회, A\* 4회.** 안 꺼내진 정점은 **C**다.

C에서 갈린 이유를 보라. C의 `g`는 5로 B와 같다. 다익스트라는 `g`만 보므로 C를 B와 같은 급으로 취급해 꺼낸다. A\*는 `f(C) = 5 + 4 = 9`라 G의 7보다 뒤로 밀린다. **C를 거치는 경로는 아무리 잘돼도 9이고, 이미 7짜리 답이 손에 있다** — 휴리스틱이 그 사실을 미리 말해 준 것이다.

두 탐색이 낸 답은 **똑같이 7**이다. `S → B → G`. ==A\*가 주는 것은 더 짧은 답이 아니라 같은 답에 드는 더 적은 확장이다.== 이 문장이 §4의 실측 표를 읽는 열쇠다.
:::

## 4. 구현 — 뼈대 하나

§1의 명제를 코드로 세운다. 함수는 하나이고, 인자로 받는 것은 **우선순위 계수 하나**다. `f = 10·g + ε₁₀·h`에서 `ε₁₀ = 0`이면 다익스트라, `10`이면 A\*, 그 위는 Weighted A\*다. 정수로만 계산하려고 ε를 10배 해서 넘긴다.

BFS는 따로 짠다. 그 자체가 주장이기 때문이다 — **가중치가 전부 1이면 힙 없는 큐 하나로 같은 답이 같은 확장 수에 나온다.**

::: dual
```python title="우선순위 하나만 바꾸는 탐색 뼈대"
import heapq
from collections import deque

grid = [".......~~~~~~~~",
        ".......~~~~~~~~",
        ".......~~~~~~~~",
        ".......~~~~~~~~",
        ".......~~~~~~~~",
        ".......~~~~~~~~",
        ".......~~~~~~~~",
        ".......~~~~~~~~",
        ".......~~~~~~~~",
        ".######~~~~~~~~",
        ".#.....~~~~~~~~",
        ".#.....~~~~~~~~",
        ".#.....~~~~~~~~",
        "....#..........",
        "....#.........."]
H, W = len(grid), len(grid[0])
GOAL = (14, 14)
DR, DC = (-1, 1, 0, 0), (0, 0, -1, 1)


def weight(r, c, uniform):
    """칸에 드는 비용. uniform 이면 전부 1 — 그 순간 이 격자는 무가중 그래프다."""
    if grid[r][c] == '#':
        return -1
    if uniform:
        return 1
    return 4 if grid[r][c] == '~' else 1


def h(r, c):
    """맨해튼 거리. 4-이웃이고 칸 비용이 1 이상이라 실제 비용을 넘지 않는다."""
    return abs(r - GOAL[0]) + abs(c - GOAL[1])


def search(eps10, uniform):
    """f = 10*g + eps10*h. eps10=0 이면 다익스트라, 10 이면 A*, 그 위는 Weighted A*."""
    INF = 10 ** 9
    dist = [[INF] * W for _ in range(H)]
    dist[0][0] = 0
    pq = [(0, 0, 0, 0)]                    # (f, g, r, c)
    expanded = 0
    while pq:
        f, g, r, c = heapq.heappop(pq)
        if g > dist[r][c]:
            continue                       # 낡은 항목. 확장으로 세지 않는다
        expanded += 1
        if (r, c) == GOAL:
            return expanded, g
        for k in range(4):
            nr, nc = r + DR[k], c + DC[k]
            if not (0 <= nr < H and 0 <= nc < W):
                continue
            wcost = weight(nr, nc, uniform)
            if wcost < 0:
                continue
            ng = g + wcost
            if ng < dist[nr][nc]:
                dist[nr][nc] = ng
                heapq.heappush(pq, (10 * ng + eps10 * h(nr, nc), ng, nr, nc))
    return expanded, -1


def bfs():
    """가중치가 전부 1일 때의 기준선. 힙이 없고 큐 하나뿐이다."""
    dist = [[-1] * W for _ in range(H)]
    dist[0][0] = 0
    q = deque([(0, 0)])
    expanded = 0
    while q:
        r, c = q.popleft()
        expanded += 1
        if (r, c) == GOAL:
            return expanded, dist[r][c]
        for k in range(4):
            nr, nc = r + DR[k], c + DC[k]
            if 0 <= nr < H and 0 <= nc < W and dist[nr][nc] < 0 and grid[nr][nc] != '#':
                dist[nr][nc] = dist[r][c] + 1
                q.append((nr, nc))
    return expanded, -1


e, d = bfs()
print(f"uniform BFS            expand={e:3d} cost={d}")
e, d = search(0, True)
print(f"uniform Dijkstra       expand={e:3d} cost={d}")
for eps10 in (0, 10, 15, 25, 40):
    e, d = search(eps10, False)
    print(f"terrain eps={eps10 / 10:.1f}        expand={e:3d} cost={d}")
```
```cpp title="우선순위 하나만 바꾸는 탐색 뼈대"
#include <array>
#include <cstdio>
#include <deque>
#include <queue>
#include <string>
#include <vector>
using namespace std;

vector<string> grid = {".......~~~~~~~~",
                       ".......~~~~~~~~",
                       ".......~~~~~~~~",
                       ".......~~~~~~~~",
                       ".......~~~~~~~~",
                       ".......~~~~~~~~",
                       ".......~~~~~~~~",
                       ".......~~~~~~~~",
                       ".......~~~~~~~~",
                       ".######~~~~~~~~",
                       ".#.....~~~~~~~~",
                       ".#.....~~~~~~~~",
                       ".#.....~~~~~~~~",
                       "....#..........",
                       "....#.........."};
const int H = 15, W = 15;
const int GR = 14, GC = 14;
const int DR[4] = {-1, 1, 0, 0}, DC[4] = {0, 0, -1, 1};

int weight(int r, int c, bool uniform) {
    if (grid[r][c] == '#') return -1;
    if (uniform) return 1;
    return grid[r][c] == '~' ? 4 : 1;
}

int h(int r, int c) { return abs(r - GR) + abs(c - GC); }

pair<int, int> search_grid(int eps10, bool uniform) {
    const int INF = 1000000000;
    vector<vector<int>> dist(H, vector<int>(W, INF));
    dist[0][0] = 0;
    priority_queue<array<int, 4>, vector<array<int, 4>>, greater<array<int, 4>>> pq;
    pq.push({0, 0, 0, 0});                 // (f, g, r, c)
    int expanded = 0;
    while (!pq.empty()) {
        auto [f, g, r, c] = pq.top();
        pq.pop();
        if (g > dist[r][c]) continue;      // 낡은 항목. 확장으로 세지 않는다
        expanded++;
        if (r == GR && c == GC) return {expanded, g};
        for (int k = 0; k < 4; k++) {
            int nr = r + DR[k], nc = c + DC[k];
            if (!(0 <= nr && nr < H && 0 <= nc && nc < W)) continue;
            int wcost = weight(nr, nc, uniform);
            if (wcost < 0) continue;
            int ng = g + wcost;
            if (ng < dist[nr][nc]) {
                dist[nr][nc] = ng;
                pq.push({10 * ng + eps10 * h(nr, nc), ng, nr, nc});
            }
        }
    }
    return {expanded, -1};
}

pair<int, int> bfs() {
    vector<vector<int>> dist(H, vector<int>(W, -1));
    dist[0][0] = 0;
    deque<pair<int, int>> q = {{0, 0}};
    int expanded = 0;
    while (!q.empty()) {
        auto [r, c] = q.front();
        q.pop_front();
        expanded++;
        if (r == GR && c == GC) return {expanded, dist[r][c]};
        for (int k = 0; k < 4; k++) {
            int nr = r + DR[k], nc = c + DC[k];
            if (0 <= nr && nr < H && 0 <= nc && nc < W && dist[nr][nc] < 0
                && grid[nr][nc] != '#') {
                dist[nr][nc] = dist[r][c] + 1;
                q.push_back({nr, nc});
            }
        }
    }
    return {expanded, -1};
}

int main() {
    auto [e0, d0] = bfs();
    printf("uniform BFS            expand=%3d cost=%d\n", e0, d0);
    auto [e1, d1] = search_grid(0, true);
    printf("uniform Dijkstra       expand=%3d cost=%d\n", e1, d1);
    for (int eps10 : {0, 10, 15, 25, 40}) {
        auto [e, d] = search_grid(eps10, false);
        printf("terrain eps=%.1f        expand=%3d cost=%d\n", eps10 / 10.0, e, d);
    }
    return 0;
}
```

**복잡도:** `search`는 시간 $O(E \log V)$ — 간선마다 힙에 최대 한 번 push되므로 힙 연산이 $O(E)$회이고 각각 $O(\log V)$다. 격자에서는 $E = 4V$이므로 $O(V \log V)$가 된다. `bfs`는 시간 $O(V+E)$ — 정점이 큐에 정확히 한 번 들어가고 나올 때 이웃 네 개를 본다. **`log V`가 사라지는 것이 무가중 그래프의 유일한 이득이다.** 공간은 둘 다 $O(V)$이고, 힙 쪽은 낡은 항목이 쌓여 상수가 몇 배 크다.

이 여섯 줄이 Part V 전체의 요약이다.

- **1행과 2행이 같다.** 가중치가 전부 1이면 다익스트라의 힙은 큐로 퇴화한다. 확장 수 214도 비용 28도 정확히 같다. ==BFS는 다익스트라의 특수한 경우다.==
- **3행에서 비용이 30으로 오른다.** 지형 비용을 켜면 최단 "칸 수"와 최단 "비용"이 갈라진다. 28칸짜리 길은 늪을 지나므로 더 비싸고, 최적 경로는 30이 든다.
- **4행이 A\*다.** 답은 3행과 같은 30인데 확장이 164에서 100으로 줄었다. **39% 감소.** §3의 손추적에서 C를 안 꺼낸 것과 같은 일이 100번쯤 일어난 것이다.
- **6·7행이 Weighted A\*다.** 확장이 53, 39로 급감하고 비용은 43이 된다. ε=2.5의 보장은 $2.5 \times 30 = 75$ 이하이고 실제 43이 나왔다. **최적성을 속도와 바꾼 값이 숫자로 찍혀 있다.**
- **5행을 빼지 않았다.** ε=1.5는 확장 107로 A\*의 100보다 **오히려 많고** 비용은 32로 더 나쁘다. ==확장 수는 ε에 대해 단조롭지 않다.== 휴리스틱을 부풀리면 탐색이 목표 쪽으로 쏠리지만, 잘못된 쪽으로 쏠리면 되돌아오는 비용을 다시 문다. ε는 튜닝 파라미터이고 튜닝은 실측으로 한다.

| 언어 차이 | Python | C++ |
|---|---|---|
| 힙 방향 | `heapq`는 최소 힙 고정 | `priority_queue`는 **최대 힙 기본**. `greater<>`를 명시해야 최소 힙 |
| 힙 원소 | 튜플. 사전식 비교가 공짜 | `array<int,4>`. `pair`를 중첩하는 것보다 읽기 쉽다 |
| 동점 처리 | 튜플의 나머지 성분으로 결정된다 | 같다. `(f, g, r, c)`를 통째로 비교하므로 두 언어의 확장 순서가 일치한다 |
| 큐 | `collections.deque` | `std::deque`. `list.pop(0)`에 해당하는 함정이 `vector::erase(begin())` |

::: pitfall
- **비교 키에 `g`를 안 넣는 것.** `(f, r, c)`만 비교하면 `f`가 같은 두 항목의 순서가 언어마다 달라져 확장 수가 재현되지 않는다. 답은 같지만 **버그를 재현할 수 없게 된다.**
- **낡은 항목을 확장으로 세는 것.** `dist`가 이미 더 작으면 그 항목은 건너뛰어야 하고, 세면 안 된다. 이 한 줄이 없으면 `expand` 수치가 부풀어 비교가 무의미해진다.
- **`h`가 실제 비용을 넘는 것.** 이 격자에서 지형 비용이 1보다 작아지는 순간 맨해튼 거리는 과대평가가 되고 A\*는 최적을 놓친다. **휴리스틱의 admissibility는 간선 비용의 하한에 의존한다**([V-5](#/v-5)).
:::

## 5. 무엇을 고를 것인가

질문은 여섯 개다. 위에서부터 던져 처음 걸리는 곳에서 멈춘다.

| 질문 | 예 | 알고리즘 | 대가 |
|---|---|---|---|
| 간선 비용이 전부 같은가 | 예 | [BFS](#/iv-3) $O(V+E)$ | 없음. 가장 싸다 |
| 비용이 0과 1뿐인가 | 예 | [0-1 BFS](#/iv-4) $O(V+E)$ | 덱을 써야 한다 |
| 음수 간선이 있는가 | 예 | [벨만-포드](#/v-2) $O(VE)$ | 느리다. 대신 음수 사이클을 검출한다 |
| 모든 쌍이 필요한가 | 예 | [플로이드-워셜](#/v-3) $O(V^3)$ | $V \le 500$ 정도까지 |
| 목표가 하나이고 거리 추정이 되는가 | 예 | [A\*](#/v-5) | 휴리스틱 설계. admissible해야 최적 |
| 최적이 아니어도 빠른 게 급한가 | 예 | [Weighted A\*](#/v-6) | 답이 최대 ε배. 단조롭지 않다 |
| — | 아니오 | [다익스트라](#/v-1) $O(E \log V)$ | 기본값 |

그다음은 **환경이 알고리즘을 고르는** 층이다.

| 상황 | 어디로 | 왜 |
|---|---|---|
| 실행 중에 장애물이 새로 발견된다 | [D\* Lite](#/v-7) | 전체 재계산 없이 영향 구간만 |
| 여러 대가 같은 통로를 쓴다 | [시공간 A\*](#/v-8) → [CBS](#/v-9) | 상태에 시간 축, 충돌을 제약으로 |
| 서로 기다리다 멈춘다 | [교착 검출과 회피](#/v-10) | 경로가 있어도 실행이 안 된다 |
| 누가 어디로 갈지가 안 정해졌다 | [할당 문제](#/v-11) | 비용 행렬의 칸이 최단경로 거리다 |
| 명령을 제어 주기마다 내야 한다 | [지역 경로계획](#/v-12) | 전역 경로는 궤적이 아니다 |
| 상태가 연속이고 차원이 높다 | [샘플링 기반 계획](#/v-13) | 정점을 열거할 수 없다 |

::: tip
실제 시스템은 이 표에서 **하나만** 고르지 않는다. 창고 관제 시스템 하나에 전부 들어간다 — 정적 지도에 A\*, 장애물이 생기면 D\* Lite, 로봇들 사이 충돌은 시공간 A\*, 배차는 헝가리안, 바퀴 명령은 DWA. **표는 배타적 선택지가 아니라 계층이다.**
:::

## 6. 왼쪽 끝과 오른쪽 끝

이 Part는 한 문장을 증명하려고 만들어졌다.

> **왼쪽 끝은 코딩테스트 문제이고 오른쪽 끝은 다중 로봇 관제 시스템이다. 그리고 둘은 우선순위 규칙만 다른 같은 알고리즘이다.**

§4의 출력이 그 증명이다. `search(0, True)`는 격자 최단거리를 묻는 실버 난도 문제의 답이고, 같은 함수에 `eps10`을 바꿔 넣으면 실시간 경로계획기의 핵심이 된다. 여기에 상태를 `(r, c)`에서 `(r, c, t)`로 넓히면 [V-8](#/v-8)이고, 그 위에 충돌 제약을 얹으면 [V-9](#/v-9)다. **함수 하나가 계속 살아 있다.**

그래서 이 계보를 관통해 본 사람에게는 두 가지가 동시에 생긴다. 코딩테스트에서 유형을 보고 5분 안에 결정하는 능력과, 면접에서 "왜 이 플래너를 골랐나"에 대가를 숫자로 대며 답하는 능력이다. **둘은 같은 지식이다.**

::: interview
"A\*와 다익스트라의 차이"는 이 계보에서 가장 자주 나오는 질문이다. 답의 뼈대는 세 단계다. ① 관계를 먼저 말한다 — **다익스트라는 `h = 0`인 A\*다.** 둘은 다른 알고리즘이 아니다. ② 무엇을 얻는지 정확히 말한다 — 더 짧은 답이 아니라 **같은 답에 드는 더 적은 확장**이다(§3에서 5회 대 4회, §4에서 164 대 100). ③ 조건을 붙인다 — admissible해야 최적이 보장되고, consistent가 아니면 닫힌 노드를 다시 열어야 한다([V-5](#/v-5)). 여기에 "ε를 곱하면 최적성을 속도와 바꾼다"까지 붙이면 [V-6](#/v-6)으로 이어진다.
:::

## 7. 이 유형을 알아보는 법

::: classify
- 신호어: "최소 비용으로", "가장 빠른 경로", "최단 시간", "몇 번 만에 도달" — 여기에 **무엇이 비용인가**를 이어서 물어라. 칸 수인가, 가중치 합인가, 시간인가
- 제약조건: 정점 $V \le 10^5$·간선 $E \le 5 \times 10^5$면 $O(E \log V)$가 든다. $V \le 500$이면 $O(V^3)$ 플로이드-워셜이 든다. 격자 $1000 \times 1000$은 정점 $10^6$이라 BFS는 되고 플로이드-워셜은 안 된다([0-9](#/0-9))
- 혼동 주의: 경로가 아니라 **연결 여부**만 물으면 유니온 파인드나 DFS다([IX-1](#/ix-1), [IV-2](#/iv-2)). 모든 정점을 잇는 최소 비용이면 최소 신장 트리이지 최단경로가 아니다([IX-4](#/ix-4)). 순서 제약만 있으면 위상 정렬이다([IV-6](#/iv-6))
- 반례 함정: 음수 간선이 하나라도 있으면 다익스트라는 틀린 답을 낸다. 격자에서 대각선 이동을 허용하면 맨해튼 휴리스틱이 과대평가가 되어 A\*의 최적성이 깨진다. 그리고 **가중치가 전부 1인데 힙을 쓰는 것** — 답은 맞지만 `log V`를 공짜로 낸다
:::

## 연습

::: quiz
알고리즘 이름 하나로 답하지 마라. **① 뼈대의 어느 가정이 깨졌는가 ② 무엇을 바꿔야 하는가 ③ 그 대가는 무엇인가**를 적어라.

**1. 배터리 잔량이 경로에 얽힌다**
- 상황: AGV가 이동 중 배터리를 쓰고 충전소를 지나면 회복한다. 잔량이 0이면 멈춘다. 목표까지 가장 빠른 경로를 구하라.
- 확인할 것: 이것은 왜 그냥 다익스트라가 아닌가. **상태를 무엇으로 바꿔야 하는가**(힌트: 상태는 위치 하나가 아니다). 그렇게 바꾸면 상태 공간이 몇 배가 되고, 그 곱셈이 [V-8](#/v-8)의 시간 축 추가와 무엇이 같은가.

**2. 교차로 하나를 두 대가 동시에 노린다**
- 상황: 로봇 A와 B의 경로가 교차로에서 만난다. 각자의 경로는 이미 [V-5](#/v-5)로 최적이다.
- 확인할 것: 각자 최적인 경로 두 개의 합이 왜 전체 최적이 아닌가. 우선순위 기반 계획과 [CBS](#/v-9)가 각각 무엇을 보장하고 무엇을 못 하는가. **로봇이 50대로 늘면 어느 쪽이 먼저 무너지는가.**

**3. 계획이 매 초 무효가 된다**
- 상황: 사람이 많이 다니는 구역이라 코스트맵이 초당 여러 번 바뀐다. 전역 계획에 200 ms가 걸린다.
- 확인할 것: 전역 계획을 매번 다시 돌리는 것과 [D\* Lite](#/v-7)로 증분 갱신하는 것 중 어느 쪽인가. **바뀐 셀이 전체의 30%를 넘으면 그 판단이 뒤집히는 이유**는 무엇인가. 그리고 이 구역에서 [V-12](#/v-12)의 지역 플래너에 무엇을 더 맡길 수 있는가.
:::

## 요약

- 열네 개를 열네 개로 기억하면 못 고른다. **뼈대 하나와 바뀐 지점 여섯 개**로 접어라.
- 척추는 이것이다. `BFS → 다익스트라 → A* → D* Lite → 시공간 A* → CBS`. 화살표마다 **정확히 한 가지**가 바뀐다 — 큐→우선순위 큐, `g`→`g+h`, 전체 재계산→증분, 상태→상태×시간, 1대→N대와 제약 트리.
- **가중치가 전부 1이면 다익스트라의 힙은 큐로 퇴화한다.** 실측에서 BFS와 다익스트라의 확장 수가 214로 같고 답도 28로 같다.
- **다익스트라는 `h = 0`인 A\*다.** A\*가 주는 것은 더 짧은 답이 아니라 같은 답에 드는 더 적은 확장이다(164 → 100, 39% 감소).
- **Weighted A\*는 최적성을 속도와 바꾼다.** ε=2.5에서 확장 53, 비용 43(최적 30). 그리고 ε=1.5에서 확장이 오히려 늘었다 — **확장 수는 ε에 단조롭지 않다.**
- 선택은 여섯 질문으로 접힌다. 비용이 같은가 → 0/1인가 → 음수인가 → 모든 쌍인가 → 휴리스틱이 있는가 → 최적을 포기할 수 있는가.
- 그 위에 **환경이 고르는 층**이 있다. 지도가 바뀌면 D\* Lite, 여러 대면 시공간 A\*와 CBS, 배차면 헝가리안, 바퀴 명령이면 DWA, 연속 고차원이면 RRT.
- 실제 시스템은 하나를 고르지 않고 **전부를 계층으로 쌓는다.** 왼쪽 끝의 코딩테스트 문제와 오른쪽 끝의 다중 로봇 관제는 우선순위 규칙만 다른 같은 코드다.
