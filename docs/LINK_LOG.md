# 외부 링크 검증 로그

`docs/STYLE.md` §6.7에 따라, 본문에 외부 링크를 추가할 때마다 같은 커밋에 한 줄을 남긴다.

**규칙:** 작성 시점에 실제로 접속해서 (1) 살아있는지 (2) 제목이 아니라 실제 내용이 주제와
일치하는지 확인한 뒤에만 넣는다. 추측으로 만든 URL은 넣지 않는다. 확인이 안 되면 비워 둔다.
**없는 것이 틀린 것보다 낫다.**

백준 문제 URL(`https://www.acmicpc.net/problem/{번호}`)은 결정론적 패턴이므로 이 로그에
개별 기록하지 않는다. 다른 플랫폼의 문제는 제목만 쓰고 URL을 붙이지 않는다.
