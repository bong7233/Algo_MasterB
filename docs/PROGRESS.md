**확정된 방향 (착수 전 결정)**

| 사안 | 결정 |
|---|---|
| 프로젝트 성격 | **독립 프로젝트.** 외부 레포에 지식을 위임하지 않는다. 필요한 것은 전부 이 안에서 완결 |
| 폰 복습 | **단일 HTML**(`algobook.html`) + Anki CSV. EPUB은 위젯이 죽어서 비채택 |
| 학습 관리 | SM-2 SRS 신규 구현. 챕터가 아니라 `::: classify` / `::: quiz` 항목 단위로 스케줄링 |
| 화면 대응 | **완전 반응형.** 폰에서도 본문·목차·검색·위젯이 동작 |
| 중심축 | 코딩테스트와 실무를 동등하게. Part I(유형 판별)은 그대로 1순위 |
| 언어 기초 | Part 0을 자립적 완결 레퍼런스로 강화(11 → 13챕터) |
| 툴체인 | CPython 3.13 / g++ 13 `-std=c++17 -O2` / Ubuntu 24.04 |
| 목차 확장 | **Part XV「시스템 규모의 자료구조」12챕터 신설** — B-Tree, LSM, 블룸 필터, 스킵 리스트, HyperLogLog, 머클 트리, 일관성 해싱, 캐시 정책, 레이트 리미팅, 합의, 외부 정렬 |
| 배포 | 마일스톤마다 브랜치 + 드래프트 PR / GitHub Pages / `algobook.html` 매 마일스톤 커밋 / CI 검증 |

**통보 사항**

- Part XV 신설로 위젯이 6종 추가됐다(`btree-ops`, `lsm-compaction`, `bloom-filter`, `consistent-hash-ring`, `cache-policy`, `skiplist`). M9에서 구현한다.
- Part X에 X-7「부동소수점의 함정」을 추가했다. 기하와 실수 이분 탐색 양쪽에서 반복해서 필요한데 어느 챕터에도 자리가 없었다(§11-2 목차 조정).
- 컨테이너 기본 `python3` 는 3.11이다. 벤치마크는 명시적으로 `python3.13` 으로 실행한다.

## M1 — 엔진 구축

**상태:** 완료

**만든 것**

- `index.html` — 상단바, 3단 레이아웃, 검색·복습 모달, 오버레이 드로어.
- `assets/markdown.js` — `::: dual` / `::: classify` / `::: trace` / `::: widget` 을 포함한 확장 문법 렌더러.
- `assets/highlight.js` — Python·C++ 구문 강조기.
- `assets/style.css` — 테마 2종, 반응형 4단계, 상자 14종.
- `assets/app.js` — 라우팅·목차·검색·인북 목차·진도·SM-2 SRS·언어 토글·위젯 마운트.
- `build.py` — 번들링, 자산 버전 도장, `--watch` / `--serve` / `--single`.
- `tools/` — 콘텐츠 규범·내부 링크·다이어그램 정렬 검사기, Anki 내보내기.
- `content/toc.json` — 16개 Part 147개 절. `content/glossary.json` — 용어 31개.
- `content/toolbox/0-11.md` — 손추적 방법론. 데모이자 실제 챕터.
- `.github/workflows/ci.yml`.

**검증한 것**

| 대상 | 방법 | 결과 |
|---|---|---|
| 구문 강조기 | 줄별 span 균형, 무손실 왕복, 꺾쇠 이스케이프, 비정상 입력 | 7/7 통과 |
| 마크다운 렌더러 | 계약 전 항목 + 상자 중첩 + XSS + 슬러그 일치 | 24/24 통과 |
| 통합 | 실제 브라우저(Chromium)에서 렌더·상호작용·반응형 | 36/36 통과 |
| 가로 스크롤 | 1500·1300·900·700·420·360px | 전 폭에서 없음 |
| 단일 파일 | 폰 폭에서 열기 | 외부 요청 0, 콘솔 에러 0 |

**통보 사항**

- 계약서에 `.topbar-actions` 래퍼를 적지 않아 아이콘 버튼이 세로로 쌓여 상단바를 넘어가는 결함이 있었다. 브라우저 검증에서 잡아 수정했다. `overflow-x: clip` 때문에 눈으로는 보이지 않던 결함이다.
- 드로어가 열린 동안 상단바는 오버레이 아래에 놓인다. 스크림을 눌러 닫는 것이 표준 동작이므로 그대로 둔다.
- 위젯이 없는 `::: widget` 은 자리표시자로 렌더된다. 콘텐츠가 위젯보다 먼저 쓰이므로 정상적인 중간 상태다.
