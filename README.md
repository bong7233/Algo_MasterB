# Algorithmic

알고리즘과 자료구조를 **Python과 C++ 두 언어로 동시에**, 코딩테스트부터 실제 시스템까지
**끊지 않고** 다루는 인터랙티브 학습 웹앱.

설치도, 서버도, 인터넷도 필요 없다. `index.html` 을 열면 끝이다.

---

## 이 책이 하려는 것

알고리즘 자료는 세 진영으로 갈라져 있고, 셋 다 반쪽이다.

- **코딩테스트 자료**는 문제 풀이 스킬만 다룬다. 그 알고리즘이 실제 시스템 어디에 박혀 있는지는 말하지 않는다.
- **시스템·로보틱스 자료**는 A\*, D\* Lite, ICP를 다루지만 그 밑바닥이 BFS·다익스트라·DP라는 사실을 연결해주지 않는다.
- **인프라·백엔드 자료**는 B-Tree, LSM, 블룸 필터를 "이런 게 있다"로 소개하고 끝난다.

이 책은 셋이 같은 계보임을 증명한다.

```
BFS  →  다익스트라  →  A*  →  D* Lite  →  시공간 A*  →  CBS
 └ 격자 최단거리     └ 가중 그래프   └ 휴리스틱   └ 동적 재계획   └ 다중 에이전트

해시 테이블  →  일관성 해싱  →  블룸 필터  →  HyperLogLog
 └ O(1) 조회      └ 샤딩·리밸런싱   └ 확률적 집합   └ 확률적 카디널리티

이진 탐색 트리  →  균형 트리  →  B-Tree  →  B+Tree  →  LSM Tree
 └ 정렬 유지         └ 최악 보장     └ 블록 I/O   └ DB 인덱스   └ 쓰기 최적화
```

왼쪽 끝에서 오른쪽 끝까지 끊지 않고 간다.

## 무엇이 다른가

| | |
|---|---|
| **이중 언어** | 모든 구현이 Python과 C++ 두 버전으로, 같은 변수명·같은 줄 구조로 나란히 있다. 상단 토글로 한쪽만 볼 수도 있다 |
| **위젯 우선** | 시간에 따라 변하는 것은 글로 때우지 않는다. 탐색 순서, DP 테이블 채우기, 힙 sift, B-Tree 분할 — 전부 스텝 재생 위젯이다 |
| **유형 판별을 1순위로** | 알고리즘 학습의 실질 병목은 지식의 부재가 아니라 문제-알고리즘 매핑의 실패다. Part I 전체가 그 훈련이고, 모든 챕터에 유형 판별 상자가 박혀 있다 |
| **손추적 강제** | 코드를 보여주기 **전에** 상태 표를 주고 직접 채우게 한다. 구현력의 근본은 머릿속 실행 모델이다 |
| **정답 코드 없음** | 대표문제는 번호·제목·난도와 3단 사고과정만 준다. 답이 보이면 사고과정이 죽는다 |
| **실측 수치만** | 복잡도에는 근거 한 줄이 붙고, 벤치마크는 전부 실제로 돌린 값이다. 측정 스크립트가 `tools/bench/` 에 있다 |

## 본문을 고치고 싶을 때

본문은 `content/` 아래 마크다운이다.

```bash
python3 build.py            # 한 번 빌드
python3 build.py --watch    # 저장할 때마다 자동 빌드
python3 build.py --serve    # 로컬 서버 (같은 와이파이의 폰에서 접속)
python3 build.py --single   # algobook.html 단일 파일 생성
```

`content/toc.json` 의 챕터 `id` 와 파일 이름(`<id>.md`)이 짝이다. 빌드가 `content/` 아래를
뒤져 자동으로 연결하므로 폴더 구조는 자유롭게 바꿔도 된다.

집필 규범은 [docs/STYLE.md](docs/STYLE.md) 에 있다. 새 챕터를 쓴다면 먼저 읽어라.

### 검사 도구

```bash
python3 tools/check_content.py    # 이중 언어·손추적·유형판별·복잡도 표기 누락
python3 tools/check_links.py      # 내부 id·위젯 타입 참조 무결성
python3 tools/check_diagrams.py   # 아스키 다이어그램 정렬
```
